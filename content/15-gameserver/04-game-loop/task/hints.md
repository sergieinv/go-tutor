## Подсказка 1

Держите не «сколько времени накопилось», а `next` — запланированное время следующего тика. В `NewLoop` это `clock.Now()`. Тогда сетка тиков получается сама: `next` всегда сдвигается ровно на `Interval` — после выполненного тика и после отброшенного. Сколько тиков наступило к моменту `now`: ноль, если `now < next`, иначе `(now-next)/Interval + 1` (деление `time.Duration` целочисленное).

## Подсказка 2

Если наступило больше `MaxCatchUp`, отбросьте самые старые: `Skipped += due - MaxCatchUp`, `next += (due - MaxCatchUp) * Interval`, `due = MaxCatchUp`. Каждый тик меряйте отдельно: `start := clock.Now()` до вызова `tick`, `clock.Now() - start` — после. Сон в конце — на `next - clock.Now()`, но только если это больше нуля: при догонянии спать нельзя.

## Подсказка 3

Для MSPT хватит кольца из `Window` длительностей: пока оно не заполнено, `append`, потом перезаписывайте `window[ticks % Window]` — это самая старая запись. `Stats` суммирует то, что лежит в кольце, и делит на `len(window)`; при пустом кольце MSPT и MaxMSPT — нули. `Run`:

```go
for {
	if err := ctx.Err(); err != nil {
		return err
	}
	l.Step()
}
```
