## Подсказка 1

Состояние валидатора: последняя верная позиция и её тик, номер текущего тика и счётчик пакетов в нём, флаг «отключён». `Move` — четыре проверки строго по порядку из условия, каждая с ранним `return`. Для чисел: `math.IsNaN(c) || math.IsInf(c, 0) || math.Abs(c) > MaxCoord` по каждой координате.

## Подсказка 2

Счётчик: если `tick` отличается от запомненного — запомните новый и обнулите счётчик, затем увеличьте его. Отказ по частоте — `счётчик > MaxMovesPerTick`. `elapsed` — `min(max(tick-at, 1), uint64(MaxCatchUp))`: разность беззнаковая и неотрицательна, потому что тики не убывают. Бюджет — `MaxSpeed * float64(elapsed)`.

## Подсказка 3

Условие принятия запишите так, чтобы NaN давал отказ: `if !(dx*dx+dz*dz <= budget*budget) { return Reject, pos }`. При `Reject` и `Drop` не трогайте ни позицию, ни её тик — отсчёт бюджета идёт от последней верной позиции. `Kick` ставит флаг; первым делом `Move` и `Teleport` проверяют его.
