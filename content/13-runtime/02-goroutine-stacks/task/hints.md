## Подсказка 1

Рекурсия хранит «что ещё обойти» в кадрах стека горутины, и глубина кадров равна глубине входа. Перенесите это состояние в обычный срез: `stack := []T{start}`, цикл `for len(stack) > 0`, снятие с вершины — `top := stack[len(stack)-1]; stack = stack[:len(stack)-1]`, добавление — `append`. Срез живёт в куче и растёт, сколько нужно.

## Подсказка 2

Для `MaxDepth` кладите в стек пару «узел и его глубина»: `type item struct { n *Node; depth int }`. Сняли пару — обновили максимум и положили непустых детей с `depth+1`. Порядок обхода для ответа не важен.

Для `Flood` элемент стека — координаты клетки. Перекрашивайте клетку **в момент, когда кладёте её в стек**, а не когда снимаете: иначе одна клетка попадёт в стек несколько раз и посчитается дважды.
