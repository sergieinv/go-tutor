## Подсказка 1

Разбейте `HeapGoal` на две функции — цель по GOGC и цель по лимиту — и верните меньшую (встроенная `min`). Для `GOGC < 0` первая цель — `math.MaxUint64`, и тогда всё решает лимит. Обратите внимание: без лимита (`NoLimit`) цель по лимиту — огромное, но конечное число, меньше `math.MaxUint64`.

## Подсказка 2

Порядок операций важен: `(marked+stack+globals)*gogc/100` — сначала умножение, а запас `goal/100*3` — сначала деление. Минимум по GOGC — `max(цель, HeapMinimum*gogc/100)`, запас — `max(goal/100*3, MiB)`, итог по лимиту — `max(цель, HeapMarked)`.

## Подсказка 3

В `MemoryLimit` сначала проверьте процент (`0 <= reservePercent < 100`), затем `strings.TrimSpace`, затем сравнение с `"max"` и `strconv.ParseInt(v, 10, 64)`. Отбросьте ошибки разбора, `n <= 0` и `n > MaxContainerBytes`; при ошибке возвращайте `0, ErrBadInput`. Результат — `n * int64(100-reservePercent) / 100`.
