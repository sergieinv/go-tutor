## Подсказка 1

Храните объекты в срезе (индекс — ID): у каждого слоты, цвет и признак «жив». Корни — множество (`map[int]bool`), очередь серых — срез, флаг «идёт маркировка» — `bool`. Почти всё сводится к одной функции `shade(id)`: `Nil` и не белые пропускаем, белый красим в серый и добавляем в конец очереди.

## Подсказка 2

`StartGC` собирает ID корней, сортирует их (`slices.Sort`) и вызывает `shade` для каждого. `MarkStep` снимает первый элемент очереди, вызывает `shade` для каждого слота и ставит цвет `Black`. В `Write` при идущей маркировке сначала `shade(старое значение слота)`, потом `shade(ptr)`, и только затем запись.

## Подсказка 3

`Sweep`: если маркировка не идёт — `return []int{}`. Иначе `for h.MarkStep() {}`, затем один проход по объектам: живой белый — `live = false` и ID в результат, остальным живым — цвет `White`. В конце выключите маркировку. `Alloc` смотрит на флаг маркировки: `Black`, если она идёт.
