## Подсказка 1

Если написать `defer r.Close()` прямо в цикле `UseAll`, ресурсы закроются только в конце всей функции — тест на «не больше одного открытого» это поймает. Вынесите обработку одного ресурса в отдельную функцию `useOne(open, name) error`.

## Подсказка 2

В `useOne` после успешного `open` отложите закрытие. Чтобы не потерять ошибку `Close`, сделайте результат именованным — `(err error)` — и откладывайте не `r.Close()`, а замыкание, которое может этот результат поменять.

## Подсказка 3

```go
defer func() {
	if cerr := r.Close(); cerr != nil && err == nil {
		err = cerr
	}
}()
return r.Use()
```

Условие `err == nil` сохраняет ошибку `Use`, если упали оба. Контекст добавьте в `UseAll`: `fmt.Errorf("%s: %w", name, err)`.
