## Подсказка 1

Панику можно поймать только в отложенной функции: `defer func() { r := recover(); ... }()`. Чтобы вернуть ошибку из функции, которая паниковала, сделайте результаты именованными и присвойте `err` прямо в замыкании.

## Подсказка 2

`recover` возвращает `any`. Отличите ошибку от прочих значений приведением `e, ok := r.(error)`. Для ошибки используйте `fmt.Errorf("panic: %w", e)` — `%w` сохранит её для `errors.Is`; для остального — `%v`.

## Подсказка 3

Повторная паника — это просто `panic(r)` внутри того же отложенного замыкания, до того как вы запишете ошибку:

```go
if e, ok := r.(error); ok && errors.Is(e, ErrFatal) {
	panic(r)
}
```

`panic(nil)` отдельно обрабатывать не нужно: `recover` вернёт `*runtime.PanicNilError`, а это уже `error`.
