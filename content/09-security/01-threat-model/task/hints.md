## Подсказка 1

Middleware `authn` отвечает только на вопрос «кто это». Пройдите по каждому маршруту и для каждого спросите: кому по условию разрешено это действие и в какой строке кода это проверяется? Отдельно посмотрите, какие поля нового документа берутся из тела запроса, — тело пишет клиент, и он может прислать любые поля структуры `Doc`.

## Подсказка 2

Уязвимостей четыре, и функциональные тесты ни одну не ловят: чтение и удаление по чужому `id` (IDOR), назначение владельца клиентом (mass assignment) и административный маршрут, на котором никто не смотрит на `User.Admin`. Чужой документ должен выглядеть для пользователя ровно как несуществующий — тот же `404`.

## Подсказка 3

Вынесите проверку владельца в одну функцию и вызывайте её и в `get`, и в `remove` (под мьютексом, до удаления):

```go
func (a *api) ownDoc(u User, id int64) (Doc, bool) {
	d, found := a.docs[id]
	return d, found && d.Owner == u.Name
}
```

В `create` присваивайте `d.Owner = userFrom(r).Name` безусловно. В `adminList` первым делом: `if !userFrom(r).Admin { http.Error(w, "forbidden", http.StatusForbidden); return }`.
