## Подсказка 1

Разберите версию на части: уберите `v`, отрежьте метаданные `strings.Cut(v, "+")`, затем отделите пререлиз `strings.Cut(v, "-")` — по **первому** дефису (в пререлизе псевдоверсии дефисы тоже есть). Числа — `strconv.Atoi`. Пререлиз — `strings.Split(pre, ".")`; удобно хранить `nil` для релиза, чтобы отличать его от пререлиза.

## Подсказка 2

Сравнение списков идентификаторов пререлиза — `slices.CompareFunc(a, b, compareIdent)`: он сам решает «более короткий префикс меньше». В `compareIdent` два числовых идентификатора сравнивайте как числа (без ведущих нулей можно сначала по длине, потом как строки — так не будет переполнения на 14-значной дате псевдоверсии), числовой против буквенного — `-1`.

## Подсказка 3

Разбор `go.mod` — один проход по строкам с состоянием «открыт блок такой-то директивы»:

```go
f := strings.Fields(line) // после отрезания "//..."
switch {
case block != "" && len(f) == 1 && f[0] == ")":
	block = ""
case block != "":
	handle(block, f)         // строка блока: директива — от блока
case len(f) == 2 && f[1] == "(":
	block = f[0]
default:
	handle(f[0], f[1:])
}
```

В `handle` реагируйте только на `require` и `replace`. Для `replace` найдите `=>` через `slices.Index` — старый путь всегда `f[0]`, даже если за ним идёт версия.
