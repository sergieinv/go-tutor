## Подсказка 1

Храните индексы как счётчики, которые только растут: `tail` — сколько записано, `head` — сколько прочитано. Тогда «пусто» — это `head == tail`, «полно» — `tail - head == Cap()`, а ячейка — `buf[index & mask]`, где `mask = Cap() - 1`. Чтобы `head` и `tail` не делили линию, поставьте между ними поле `_ [CacheLine - 8]byte`.

## Подсказка 2

Порядок операций — это и есть синхронизация. Производитель сначала пишет значение в ячейку, потом `tail.Store(t + 1)`. Потребитель сначала `tail.Load()`, потом читает ячейку, обнуляет её (`var zero T`) и только потом `head.Store(h + 1)`. `Len` читает сначала `head`, потом `tail` и ограничивает разность сверху ёмкостью.

## Подсказка 3

```go
func (r *Ring[T]) TryPush(v T) bool {
	t := r.tail.Load()
	if t-r.head.Load() == uint64(len(r.buf)) {
		return false
	}
	r.buf[t&r.mask] = v
	r.tail.Store(t + 1)
	return true
}
```

Ускорение: храните у производителя последний увиденный `head` (а у потребителя — `tail`) в обычном поле своей линии и перечитывайте атомик, только когда по старому значению места (или данных) нет.
