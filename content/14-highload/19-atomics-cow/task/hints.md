## Подсказка 1

`Load` — это просто `h.cur.Load()`: снимок публикуется только целиком, поэтому читателю нужна одна атомарная операция. Все изменения делаются в копии, которую ещё никто не видит. `Clone` копирует map (`maps.Clone`) — помните, что для `nil` она возвращает `nil`.

## Подсказка 2

`Update` — бесконечный цикл: прочитать текущий снимок, вызвать `f`, разобрать особые случаи (ошибка, `nil`, тот же указатель) и попытаться опубликовать `CompareAndSwap(old, next)`. Если CAS не прошёл, кто-то успел опубликовать свой снимок — начните заново, вызвав `f` ещё раз со свежим снимком. Версию проставьте в `next` до CAS: пока снимок не опубликован, его можно менять.

## Подсказка 3

```go
for {
	old := h.cur.Load()
	next, err := f(old)
	if err != nil {
		return nil, err
	}
	// nil → ErrNilConfig, next == old → вернуть old
	next.Version = old.Version + 1
	if h.cur.CompareAndSwap(old, next) {
		return next, nil
	}
}
```

`Set` — это `Update` с функцией, которая клонирует `old` и записывает ключ в копию.
