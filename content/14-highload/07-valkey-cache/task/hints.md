## Подсказка 1

У `Cache.Get` три исхода, и каждый ведёт в свою ветку: `err != nil` — кеш недоступен, сразу идите в базу и больше кеш не трогайте; `ok == true` — запись есть (пустая строка — «товара нет», иначе JSON товара); `ok == false` — промах: читаем базу и кладём результат в кеш. Ключ — `cfg.Prefix + "product:" + strconv.FormatInt(id, 10)`.

## Подсказка 2

После чтения базы различайте «товара нет» и «база сломалась»: `errors.Is(err, ErrNotFound)` — записать `""` на `NegativeTTL` (если он больше нуля) и вернуть ошибку; любая другая ошибка — вернуть как есть и ничего не кешировать, иначе пятисекундный сбой базы превратится в минуту «товара нет». Если `json.Unmarshal` записи из кеша не удался, ведите себя как при промахе.

## Подсказка 3

Запись о товаре — `json.Marshal(p)` с TTL `cfg.TTL + cfg.Jitter()` (при `Jitter == nil` подставьте функцию, возвращающую 0, ещё в `NewCatalog`). Ошибки `Set` при чтении можно игнорировать: кеш — ускоритель. В `Save` порядок такой:

```go
if err := c.store.SaveProduct(ctx, p); err != nil {
	return err // кеш не трогаем
}
if err := c.cache.Del(ctx, c.Key(p.ID)); err != nil {
	return fmt.Errorf("%w: %w", ErrInvalidate, err)
}
return nil
```
