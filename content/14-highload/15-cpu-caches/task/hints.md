## Подсказка 1

Храните элементы в `[]int64` и два числа: индекс первого элемента и количество. `Pop` не сдвигает срез и не делает `q.buf = q.buf[1:]` — это не освобождает начало массива, и следующий `append` в какой-то момент выделит новый. Двигайте индекс головы.

## Подсказка 2

Удобнее всего кольцевой буфер: следующий свободный слот — `(head + n) % len(buf)`, после `Pop` голова — `(head + 1) % len(buf)`. Если ёмкость — степень двойки, `% len` заменяется на `& (len-1)`. Когда буфер полон, выделите вдвое больший (но не меньше 8) и перепишите элементы по порядку с нуля — так очередь, которая «перешла через край», снова лежит подряд. Нулевое значение — `nil`-срез, первый `Push` его создаст.

## Подсказка 3

```go
func (q *Queue) grow() {
	buf := make([]int64, max(8, 2*len(q.buf)))
	for i := range q.n {
		buf[i] = q.buf[(q.head+i)&(len(q.buf)-1)]
	}
	q.buf, q.head = buf, 0
}
```

`All` — замыкание `func(yield func(int64) bool)`, которое проходит `i` от 0 до `n-1` по индексу `(head+i)&(len(buf)-1)` и выходит, как только `yield` вернул `false`.
