## Подсказка 1

Размер проверяйте до разбора: `data, err := io.ReadAll(io.LimitReader(r, MaxInput+1))`, и если `len(data) > MaxInput` — `ErrTooLarge`. Дальше — `strings.Split(string(data), "\n")`, номер строки — индекс + 1. У каждой строки обрежьте пробелы и табы по краям (`strings.Trim(line, " \t")`); пустые и начинающиеся с `#` пропустите. Ошибку строки оборачивайте так: `fmt.Errorf("%w: line %d: %v", ErrSyntax, n, причина)`.

## Подсказка 2

Строку ряда разбирайте посимвольно, а не `strings.Split`: внутри кавычек значения метки могут быть `,`, `}`, `=` и `#`. Имя — пока символ подходит (`[a-zA-Z0-9_:]`, не цифра первым). Если дальше `{`, то в цикле: пропустить пробелы, `}` — конец; иначе имя метки, ровно `="`, значение до неэкранированной `"` (после `\` допустимы только `\`, `"` и `n`), снова пробелы, затем `,` или `}`. После этого обязателен пробел или таб, а `strings.FieldsFunc` по пробелам и табам должен дать одно или два поля: значение — `strconv.ParseFloat(f, 64)`, метка времени — `strconv.ParseInt(f, 10, 64)`. Имена меток запоминайте в отдельном множестве (повтор ловится и у пустых), а в `Labels` кладите только непустые значения.

## Подсказка 3

Ключ ряда — имя и непустые метки в порядке имён, например `name + "\x00" + k1 + "\x00" + v1 + …` по `slices.Sorted(maps.Keys(labels))`; тот же ключ ловит дубли в `Parse`. `Increase`:

```go
prev := map[string]float64{} // ключ ряда → значение в before
// ... заполнить по рядам before с нужным именем
for _, s := range after {
	// имя совпадает и s.Labels[k] == v для всех пар match
	b, ok := prev[key(s)]
	if !valid(s.Value) || ok && !valid(b) { // valid: не NaN, не ±Inf, >= 0
		continue
	}
	if !ok || s.Value < b {
		sum += s.Value // новый ряд или сброс — счёт от нуля
	} else {
		sum += s.Value - b
	}
}
```

`Summarize` — несколько вызовов `Increase` и деление с проверкой знаменателя на ноль; длительность проверьте первой: `!(seconds > 0) || math.IsInf(seconds, 1)` — `ErrDuration` (так ловится и `NaN`).
