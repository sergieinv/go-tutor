## Подсказка 1

Пишите `AppendOrder` в `append`-стиле: `` b := append(dst, `{"id":`...) ``, затем `b = strconv.AppendInt(b, o.ID, 10)`, и так поле за полем; `strconv.AppendBool` — для `paid`. Сумму `total` накапливайте в `int64` в том же цикле по позициям, а запятую ставьте перед каждой позицией, кроме первой. Ни `fmt`, ни `encoding/json`, ни конкатенации строк — они выделяют память.

## Подсказка 2

Для строк нужна своя `appendString(b []byte, s string) []byte`: открывающая кавычка, цикл по **байтам** `for i := 0; i < len(s); i++`, `switch`: `"` и `\` — обратная косая перед байтом, `c < 0x20` — шесть байт `\`, `u`, `0`, `0` и две цифры из `"0123456789abcdef"[c>>4]` и `[c&0xf]`, иначе — сам байт. Байты UTF-8 у не-ASCII символов все не меньше `0x80`, поэтому проходят как есть. `strconv.AppendQuote` не подойдёт: это кавычки Go (`\x1f`, `\a`), а не JSON.

## Подсказка 3

Пул: `var bufPool = sync.Pool{New: func() any { b := make([]byte, 0, 4<<10); return &b }}`. В `WriteOrders`: `bp := bufPool.Get().(*[]byte)`, `b := append((*bp)[:0], '[')`, заказы через `AppendOrder(b, &orders[i])` (адрес элемента, а не копия в переменную цикла), `"]\n"`, один `w.Write(b)`, затем `*bp = b` (буфер мог вырасти — сохраните новую ёмкость) и `bufPool.Put(bp)`. Буферы больше, скажем, 64 КБ лучше не возвращать.
