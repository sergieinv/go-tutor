## Подсказка 1

Шард — это счётчик плюс безымянное поле-заполнитель `_ [N]byte`, где `N` — сколько не хватает до `CacheLine`. Размер `atomic.Int64` — 8 байт, его можно получить и через `unsafe.Sizeof(atomic.Int64{})`: размер массива в типе может быть константным выражением.

## Подсказка 2

Округление вверх до степени двойки: начните с 1 и удваивайте, пока меньше `n`, или возьмите `1 << bits.Len(uint(n-1))` для `n > 1`. Когда шардов степень двойки, `hint & (len-1)` даёт индекс в диапазоне и для отрицательного `hint`. Для `Add` подойдёт `rand.Uint32()` из `math/rand/v2` — у него нет общей блокировки.

## Подсказка 3

```go
type shard struct {
	n atomic.Int64
	_ [CacheLine - 8]byte
}

func (c *Counter) AddAt(hint int, delta int64) {
	c.shards[hint&(len(c.shards)-1)].n.Add(delta)
}
```

`Load` проходит по всем шардам и складывает `n.Load()`.
