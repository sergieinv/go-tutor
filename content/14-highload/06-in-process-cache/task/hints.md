## Подсказка 1

Возьмите `container/list` и `map[K]*list.Element`: список хранит записи от свежих к старым, map находит элемент списка по ключу за O(1). В элементе — ключ (чтобы при вытеснении хвоста удалить его и из map), значение и момент истечения. Всё — под одним `sync.Mutex`: даже `Get` меняет порядок списка, поэтому `RWMutex` здесь не поможет.

## Подсказка 2

Срок считайте при записи: `exp = now() + ttl`, а «истекла» — это `ttl > 0 && !now().Before(exp)`. `Get` проверяет срок до переноса в начало: истёкшую запись удаляет из списка и map и возвращает промах, свежую — `MoveToFront` и значение. `Set` существующего ключа обновляет значение и `exp` и тоже делает `MoveToFront`.

## Подсказка 3

Вытеснение — только при вставке нового ключа и только по длине списка, без оглядки на сроки:

```go
c.m[k] = c.ll.PushFront(&item[K, V]{key: k, val: v, exp: exp})
if c.ll.Len() > c.cap {
	back := c.ll.Back()
	c.ll.Remove(back)
	delete(c.m, back.Value.(*item[K, V]).key)
}
```

`Len` обходит список и считает неистёкшие, `Purge` обходит и удаляет истёкшие — запомните `el.Next()` до удаления элемента.
