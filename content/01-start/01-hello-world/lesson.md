Программа на Go — это пакет `main` с функцией `main`. Никакого `class Program`, `static void Main(string[] args)` и `namespace`: точка входа — обычная функция верхнего уровня без параметров и без возвращаемого значения. Аргументы командной строки лежат в `os.Args`, код возврата задаёт `os.Exit`.

Запуск — одна команда: `go run main.go` (или `go run .` в каталоге модуля) компилирует программу во временный бинарник и сразу его запускает. Никакого рантайма ставить не нужно: `go build` выдаёт один статически слинкованный исполняемый файл.

## Как это в C#

- В C# точка входа — статический метод `Main` внутри класса (или top-level statements, которые компилятор сам заворачивает в класс). В Go функции живут прямо в пакете, классов нет вообще.
- `namespace` и `using` в Go заменяет пара `package` + `import`. Импортируется пакет целиком, обращение к его членам — всегда через имя пакета: `fmt.Println`, а не просто `Println`.
- `Main` может вернуть `int` и принять `string[] args`. `main` в Go не принимает и не возвращает ничего: аргументы — `os.Args`, код возврата — `os.Exit(code)`.
- `Console.WriteLine` — это `fmt.Println`, а интерполяцию `$"…{x}…"` заменяет `fmt.Printf` с вербами вроде `%v` и `%d`.

## Ловушки

### Фигурная скобка на новой строке

Стиль Allman из C# в Go не компилируется:

```go
func main()
{ // syntax error: unexpected semicolon or newline before {
	fmt.Println("hi")
}
```

Лексер сам вставляет `;` в конце строки, если она заканчивается идентификатором, литералом, `)` или `}`. После `func main()` появляется точка с запятой, и `{` на следующей строке уже ни к чему не относится. Открывающая скобка всегда на той же строке.

### Лишний импорт — ошибка компиляции

```go
import (
	"fmt"
	"os" // "os" imported and not used
)
```

Неиспользуемый импорт — не предупреждение, а ошибка. Редакторы с `goimports` добавляют и убирают импорты сами.

### `Print` и `Println` расставляют пробелы по-разному

`Println` ставит пробел между любыми аргументами. `Print` — только между двумя соседними аргументами, если ни один из них не строка:

```go
fmt.Print("a", "b", 1, 2, "\n") // ab1 2
fmt.Println("a", "b", 1, 2)     // a b 1 2
```

## Задание

Напишите функцию `Banner(title string) string`, которая рисует рамку вокруг строки:

```
+-------+
| Hello |
+-------+
```

Требования:

- результат — три строки, разделённые `\n`, без перевода строки в конце;
- между рамкой и текстом — ровно один пробел с каждой стороны, ширина рамки подстраивается под длину `title`;
- для пустого `title` получается `+--+`, `|  |`, `+--+`;
- `title` содержит только ASCII-символы, так что длина в байтах (`len`) равна числу символов.
