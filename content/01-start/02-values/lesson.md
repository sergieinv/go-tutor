Базовые типы Go почти совпадают с C#: `string`, `bool`, целые `int8`…`int64` и `uint8`…`uint64`, `float32` и `float64`. `int` и `uint` — машинного размера: на 64-битных платформах это 64 бита, а не 32, как `int` в C#. `byte` — псевдоним `uint8`, `rune` — псевдоним `int32` (кодовая точка Unicode).

Главное отличие — в Go **нет неявных преобразований** между числовыми типами. Даже `int32` в `int64` и `int` в `float64` переводятся только явно: `float64(n)`. Смешивать типы в одном выражении нельзя — компилятор требует, чтобы операнды совпадали.

## Как это в C#

- В C# `int` всегда 32 бита, `long` — 64. В Go `int` зависит от платформы (на amd64 и arm64 — 64 бита); фиксированный размер дают `int32` и `int64`.
- C# сам расширяет `int` до `long` и `double`. В Go `var x int64 = n` при `n int` — ошибка компиляции, нужно `int64(n)`.
- Приведение в C# пишется `(double)n`, в Go — как вызов функции: `float64(n)`. Преобразования между `string` и числами — не приведение, а функции пакета `strconv`.
- `bool` в Go, как и в C#, не преобразуется в число и обратно. `if n {}` не скомпилируется.

## Ловушки

### Переполнение молча заворачивается

```go
var b uint8 = 255
b++
fmt.Println(b) // 0
```

Режима `checked` нет: целочисленное переполнение во время выполнения не паникует. Переполнение **константы** при этом — ошибка компиляции: `var b uint8 = 256` не соберётся.

### `string(n)` — это не `ToString()`

```go
n := 65
fmt.Println(string(rune(n)))  // A — символ с кодом 65
fmt.Println(strconv.Itoa(n))  // 65
fmt.Println(fmt.Sprint(n))    // 65
```

Преобразование целого в `string` даёт символ с таким кодом. Для `int` напрямую (`string(n)`) это настолько частая ошибка, что `go vet` на ней ругается.

### Деление целых и усечение дробных

```go
fmt.Println(7/2, -7/2) // 3 -3: деление целых отбрасывает дробную часть
f := -2.9
fmt.Println(int(f))    // -2: усечение к нулю, а не округление
```

Чтобы поделить «по-честному», один из операндов переводят в `float64` **до** деления: `float64(a) / float64(b)`. `float64(a / b)` уже поздно — деление было целым.

## Задание

Напишите две функции.

`Percent(part, total int) float64` возвращает, сколько процентов `part` составляет от `total`:

- результат округляется до одного знака после запятой функцией `math.Round` (половина — от нуля): `Percent(1, 3)` — `33.3`, `Percent(2, 3)` — `66.7`;
- `part` может быть больше `total` или отрицательным: `Percent(150, 100)` — `150`, `Percent(-1, 4)` — `-25`;
- если `total <= 0`, результат `0`.

`AddSat(a, b uint8) uint8` складывает с насыщением: если сумма не помещается в `uint8`, результат `255`, а не «завёрнутое» значение. `AddSat(200, 100)` — `255`, `AddSat(100, 55)` — `155`.
