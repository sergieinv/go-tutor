Переменную объявляют двумя способами. `var name T = value` — полная форма, в ней можно опустить либо тип, либо значение. `name := value` — короткая форма с выводом типа, аналог `var` в C#; она работает только внутри функций.

Неинициализированных переменных в Go не бывает: без явного значения переменная получает **нулевое значение** своего типа — `0`, `""`, `false` или `nil` для указателей, срезов, map и интерфейсов. У `string` нет `null`: пустая строка и есть «отсутствие значения».

## Как это в C#

- `var x = 5;` в C# — это `x := 5` в Go. Но в Go тип пишется **после** имени: `var x int`, а не `int x`.
- Локальную переменную C# нельзя читать до присваивания (CS0165). В Go она всегда инициализирована нулём, и читать её можно сразу.
- `string` в C# — ссылочный тип и может быть `null`. В Go `string` — значение, его нулевое значение — `""`, сравнение с `nil` не скомпилируется.
- Неиспользуемая локальная переменная в C# — предупреждение CS0168/CS0219. В Go — ошибка компиляции.

## Ловушки

### Затенение через `:=` во вложенном блоке

```go
count := 0
if true {
	count := 10 // новая переменная, видна только в блоке
	fmt.Println(count) // 10
}
fmt.Println(count) // 0
```

`:=` во вложенном блоке объявляет **новую** переменную, даже если снаружи есть одноимённая. Особенно коварно это с `err`: `v, err := f()` внутри `if` создаёт свой `err`, а внешний остаётся `nil`. `go vet` такое не ловит; помогает правило «внутри блока присваивать через `=`».

### `:=` требует хотя бы одну новую переменную

```go
a, err := strconv.Atoi("1")
b, err := strconv.Atoi("2") // ок: b новая, err просто присваивается
a := 3                      // ошибка: no new variables on left side of :=
```

### Неиспользуемая переменная не компилируется

```go
func main() {
	x := compute() // declared and not used: x
}
```

Если значение действительно не нужно, присвойте его пустому идентификатору: `_ = compute()`. Неиспользуемые переменные уровня пакета и параметры функций ошибкой не считаются.

## Задание

Напишите две функции, используя множественное присваивание вместо временных переменных.

`Fib(n int) int` возвращает n-е число Фибоначчи: `Fib(0) = 0`, `Fib(1) = 1`, `Fib(n) = Fib(n-1) + Fib(n-2)`.

- для `n < 0` результат `0`;
- функция должна работать быстро для `n` до 90 включительно (результат помещается в `int`), поэтому рекурсия «в лоб» не годится — нужен цикл.

`GCD(a, b int) int` возвращает наибольший общий делитель по алгоритму Евклида.

- результат всегда неотрицательный: `GCD(-12, 18) = 6`;
- `GCD(a, 0) = |a|`, `GCD(0, 0) = 0`.
