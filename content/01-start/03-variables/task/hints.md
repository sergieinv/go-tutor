## Подсказка 1

Обе функции — цикл, в котором пара значений сдвигается на шаг: в `Fib` это два последних числа последовательности, в `GCD` — делимое и делитель. Единственный цикл в Go — `for`: `for i := 0; i < n; i++ {}` или `for range n {}`.

## Подсказка 2

Множественное присваивание сначала вычисляет всю правую часть, поэтому `a, b = b, a+b` корректно сдвигает пару без временной переменной. Для Евклида то же самое: `a, b = b, a%b`, пока `b != 0`.

## Подсказка 3

`Fib`: начните с `a, b := 0, 1`, повторите сдвиг `n` раз и верните `a` (при `n <= 0` цикл не выполнится ни разу). `GCD`: после цикла `a` может оказаться отрицательным — `%` в Go сохраняет знак делимого, — поэтому верните `-a`, если `a < 0`.
