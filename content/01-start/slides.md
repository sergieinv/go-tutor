# Старт и инструменты

Обзор модуля для показа команде: как устроен Go-проект без классов, namespace и null — от первой программы до `go vet`.

---

## Точка входа — просто функция

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello, World")
}
```

| C# | Go |
|---|---|
| `static void Main(string[] args)` в классе | `func main()` в пакете `main` |
| `args`, `return 1` | `os.Args`, `os.Exit(1)` |
| `Console.WriteLine`, `$"…{x}"` | `fmt.Println`, `fmt.Printf("%v", x)` |

---

## Компилятор строже, чем привычно

- `{` всегда на той же строке: лексер сам ставит `;` после `func main()`, и стиль Allman не компилируется.
- Неиспользуемый импорт или локальная переменная — ошибка компиляции, а не предупреждение.
- Предупреждений у компилятора нет вообще: либо ошибка, либо ничего.
- Не нужное значение отдают пустому идентификатору: `_ = compute()`.

---

## Типы: без неявных преобразований

- `int` — машинного размера: на amd64 и arm64 это 64 бита, а не 32, как в C#.
- `byte` — это `uint8`, `rune` — `int32` (кодовая точка Unicode).
- Даже `int` в `int64` или `float64` переводят явно, как вызов функции:

```go
n := 7
var x int64 = int64(n)        // без int64(...) не скомпилируется
avg := float64(n) / 2         // 3.5
fmt.Println(x, avg, 7/2, -7/2) // 7 3.5 3 -3
```

---

## Числа без страховки

| Ожидание из C# | Что делает Go |
|---|---|
| `checked` / `OverflowException` | переполнение молча заворачивается: `uint8(255)+1 == 0` |
| `n.ToString()` | `strconv.Itoa(n)`; `string(rune(65))` — это `"A"` |
| `(int)-2.9` — усечение | `int(-2.9)` тоже `-2`: к нулю, не округление |

Переполнение **константы** (`var b uint8 = 256`) — уже ошибка компиляции.

---

## Переменные и нулевые значения

- `var x int` или `x := 5` — тип пишется после имени, `:=` работает только внутри функций.
- Неинициализированных переменных нет: `0`, `""`, `false`, `nil`.
- У `string` нет `null`: сравнение строки с `nil` не скомпилируется.
- `:=` во вложенном блоке объявляет **новую** переменную и затеняет внешнюю — особенно коварно с `err`.

---

## Нетипизированные константы

`const KiB = 1024` — «просто число»: подставляется и в `int64`, и в `float64` без преобразований и считается с произвольной точностью.

```go
const a, b = 0.1, 0.2
fmt.Println(a+b == 0.3) // true: точно, на этапе компиляции
x, y := 0.1, 0.2
fmt.Println(x+y == 0.3) // false: float64 во время выполнения
```

`var f float64 = 7 / 2` — это `3`: целые константы делятся нацело.

## Модуль, пакет, видимость

- Пакет — это каталог: все файлы в нём объявляют один `package` и видят друг друга целиком.
- Модуль — дерево пакетов с `go.mod` в корне; путь импорта = путь модуля + каталог.

| C# | Go |
|---|---|
| `namespace` (логический) | пакет = каталог |
| `public` / `private` | регистр первой буквы: `Total` / `total` |
| `internal` уровня сборки | каталог `internal/` |
| `PackageReference`, lock-файл | `go.mod` (версии) и `go.sum` (хеши) |

---

## Видимость касается и библиотек

```go
type User struct {
	Name string
	age  int // encoding/json — другой пакет, поле он не видит
}
b, _ := json.Marshal(User{"Ann", 30})
fmt.Println(string(b)) // {"Name":"Ann"}
```

Никакой ошибки — поле молча пропущено. Циклические импорты запрещены: `import cycle not allowed`.

## Один инструмент — `go`

```sh
go run .                  # собрать и запустить пакет
go build -o app ./cmd/app # один статический бинарник
go test ./...             # все тесты модуля
go vet ./...              # подозрительный, но компилируемый код
gofmt -l -w .             # единый стиль, без настроек
```

Раскладка: `cmd/<бинарник>/main.go` и `internal/` для кода, закрытого от других модулей.

---

## `go vet` ловит то, что пропускает компилятор

```go
fmt.Printf("%d items\n", "five") // %!d(string=five) items
fmt.Println("total: %d", 5)      // total: %d 5
```

- Форматная строка для компилятора — просто строка; программа напечатает мусор.
- `go test` сам запускает часть проверок vet и при находке не стартует: `[build failed]`.
- `go run main.go` видит только один файл — для пакета целиком пишите `go run .`.

---

## Что запомнить

- Точка входа — `func main()` в пакете `main`, классов нет.
- Преобразования типов только явные, `int` — 64 бита, переполнение не проверяется.
- Нулевые значения вместо `null`; `:=` во вложенном блоке затеняет.
- Пакет = каталог, видимость = регистр первой буквы.
- `gofmt` и `go vet` — часть нормы, а не договорённость команды.
