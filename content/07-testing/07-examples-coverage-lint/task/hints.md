## Подсказка 1

`FormatMoney`: `-5 / 100` в Go равно `0`, а `-5 % 100` — `-5`, поэтому `fmt.Sprintf("%d.%02d", kop/100, kop%100)` для отрицательных печатает чепуху вроде `0.-5`. Выведите знак отдельно и работайте с модулем. Модуль `math.MinInt64` в `int64` не помещается — возьмите `u := uint64(kop)` и для отрицательных `u = -u`: в беззнаковой арифметике это даёт верный модуль.

## Подсказка 2

`WriteReceipt` удобно делать в два прохода. Первый — проверить все позиции (ошибка до первой записи) и собрать срезы готовых названий и сумм, включая строку `Итого`. Второй — посчитать ширины: для названий `utf8.RuneCountInString`, а не `len` (кириллица — по два байта на букву), для сумм хватит `len`, — и напечатать строки.

## Подсказка 3

`fmt` умеет выравнивать сам и считает ширину в рунах; `*` берёт ширину из аргумента:

```go
for i := range labels {
	if _, err := fmt.Fprintf(w, "%-*s  %*s\n", nameW, labels[i], sumW, sums[i]); err != nil {
		return err
	}
}
```

`%-*s` дополняет справа, `%*s` — слева. Ошибку `Fprintf` возвращайте сразу: следующая запись в сломанный `Writer` бессмысленна.
