## Подсказка 1

`tb.Helper()` — первая строка обеих функций. Файл читает `os.ReadFile`, пишет `os.WriteFile(path, []byte(got), 0o644)`, каталог создаёт `os.MkdirAll(filepath.Dir(path), 0o755)`. После `tb.Fatalf` код не выполняется (как и у настоящего `*testing.T`), но `return` после записи при `update` нужен — иначе дойдёте до сравнения.

## Подсказка 2

Сравнивайте строки по индексу `i = 0, 1, 2, …`, пока они совпадают. Удобно завести функцию, которая для индекса за концом среза возвращает `"<EOF>"`, а иначе — `strconv.Quote(lines[i])`: тогда «строка закончилась» и «строка отличается» обрабатываются одним сравнением. Если тексты различаются, такой индекс обязательно найдётся.

## Подсказка 3

```go
func Swap[T any](tb testing.TB, p *T, v T) {
	tb.Helper()
	old := *p
	*p = v
	tb.Cleanup(func() { *p = old })
}
```

`defer` здесь не подходит: он вернул бы значение сразу при выходе из `Swap`, а `Cleanup` — после теста. Каждый `Swap` запоминает своё `old`, и обратный порядок Cleanup-функций возвращает исходное значение.
