## Подсказка 1

Для `AppendInts` всё уже есть в стандартной библиотеке: `append(dst, sep...)` дописывает строку в `[]byte`, а `strconv.AppendInt(dst, int64(n), 10)` — число. Обе функции пишут в тот же массив, пока хватает ёмкости, и сами растят его, когда не хватает.

## Подсказка 2

Одна аллокация в `JoinInts` — это `strings.Builder` с `Grow` на точный (или заведомо достаточный) размер результата: тогда буфер не перевыделяется, а `b.String()` возвращает строку без копирования. А вот `string(AppendInts(nil, ...))` — минимум две аллокации: рост среза и копия при преобразовании в строку. Размер посчитайте заранее: длины разделителей плюс число цифр каждого числа (и минус для отрицательных).

## Подсказка 3

Число записывайте через временный массив на стеке — он не уходит в кучу:

```go
var b strings.Builder
b.Grow(size)
var tmp [20]byte // хватит на любое int64 со знаком
for i, n := range nums {
	if i > 0 {
		b.WriteString(sep)
	}
	b.Write(strconv.AppendInt(tmp[:0], int64(n), 10))
}
return b.String()
```

Длину числа удобно считать в `uint64`: для `math.MinInt` выражение `-n` переполняется, а `-uint64(n)` даёт правильный модуль. Для пустого `nums` верните `""` до `Grow`.
