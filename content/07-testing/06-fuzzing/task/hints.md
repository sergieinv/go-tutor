## Подсказка 1

`Escape` в шаблоне верна: сначала удваиваются обратные косые черты, потом экранируются запятые и переводы строк. Ломается обратный путь. Цепочка `ReplaceAll` смотрит на строку целиком и не знает, где начинается последовательность: в `\\n` (экранированная `\` и буква `n`) она находит `\n` со второго символа. Проверьте руками `Unescape(Escape("\\n"))` — то есть строку из двух символов `\` и `n`.

## Подсказка 2

Раскодируйте одним проходом слева направо: обычный байт копируйте, а встретив `\`, сразу забирайте и следующий байт и решайте по нему (`\`, `,`, `n` или ошибка). Так каждая обратная косая черта принадлежит ровно одной последовательности. Тот же приём нужен в `Split`: идите по байтам, после `\` пропускайте следующий байт, а делите только по запятой, до которой вы дошли «не в последовательности».

## Подсказка 3

```go
start := 0
for i := 0; i < len(line); i++ {
	switch line[i] {
	case '\\':
		i++ // следующий байт экранирован — даже если это запятая
	case ',':
		// поле line[start:i] → Unescape → append; start = i + 1
	}
}
// не забудьте последнее поле line[start:]
```

Ошибку `Unescape` для любого поля превращайте в `nil, ErrSyntax`. Пустая строка без запятых даёт одно пустое поле автоматически.
