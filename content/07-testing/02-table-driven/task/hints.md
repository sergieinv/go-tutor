## Подсказка 1

Таблица — литерал среза: `return []Case{{"имя", 2023, false}, ...}`. Для каждого из четырёх видов возьмите показательный год: 2023, 2024, 1900, 2000. Имя должно объяснять, что проверяет строка, — «делится на 100, но не на 400», а не «1900».

## Подсказка 2

Почему нужны все четыре вида: реализация «`y%4 == 0`» ошибается только на годах вроде 1900, а «забыто правило 400» — только на годах вроде 2000. Таблица без таких строк пропустит ошибку, хотя все её тесты зелёные.

## Подсказка 3

```go
var msgs []string // nil, пока нет расхождений
for _, c := range cases {
	if got := f(c.Year); got != c.Want {
		msgs = append(msgs, fmt.Sprintf("%s: IsLeap(%d) = %t, want %t", c.Name, c.Year, got, c.Want))
	}
}
return msgs
```

Не создавайте `msgs` через `make` или `[]string{}` — тогда без расхождений вернётся пустой срез, а не `nil`.
