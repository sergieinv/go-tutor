## Подсказка 1

Разделите `Do` на три части: «до» под мьютексом (решить, пускать ли вызов, и запомнить поколение), сам вызов `fn()` без мьютекса и «после» под мьютексом (учесть результат). Поля структуры: состояние, номер поколения, счётчик неудач подряд, число проб в полёте, число удачных проб и момент размыкания.

## Подсказка 2

Любая смена состояния — одна функция `setState(s)`: она меняет состояние, увеличивает поколение, обнуляет счётчики (неудачи, пробы в полёте, удачные пробы) и для `Open` запоминает `Now()`. Ленивый переход — ещё одна маленькая функция, которую вызывают в начале и `Do`, и `State`:

```go
if b.state == Open && b.now().Sub(b.openedAt) >= b.timeout {
	b.setState(HalfOpen)
}
```

## Подсказка 3

«После»:

```go
if gen != b.gen {
	return // состояние сменилось, пока шёл вызов
}
failed := b.isFailure(res)
switch b.state {
case Closed:
	// успех — failures = 0; неудача — failures++, на пороге setState(Open)
case HalfOpen:
	b.inFlight--
	// неудача — setState(Open); успех — successes++, при successes >= probes — setState(Closed)
}
```

В «до» для `HalfOpen`: если `inFlight >= probes` — `ErrOpen`, иначе `inFlight++`.
