## Подсказка 1

Начните с `g, ctx := errgroup.WithContext(ctx)` и передавайте в `f` именно этот `ctx` — его группа отменит при первой ошибке. Результаты пишите в заранее выделенный `out := make([]int, len(items))` по индексу.

## Подсказка 2

`g.SetLimit(0)` не снимает ограничение, а запрещает запуск: `Go` заблокируется навсегда. Вызывайте `SetLimit` только при `limit > 0`.

## Подсказка 3

С лимитом `g.Go` для следующего элемента может дождаться места уже после ошибки. Проверьте контекст в начале задачи:

```go
g.Go(func() error {
	if err := ctx.Err(); err != nil {
		return err // ошибка уже была — f не вызываем
	}
	v, err := f(ctx, item)
	out[i] = v
	return err
})
```

После `g.Wait()` верните `nil, err` при ошибке и `out, nil` при успехе.
