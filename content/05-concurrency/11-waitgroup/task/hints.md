## Подсказка 1

Прервать `wg.Wait()` нельзя, поэтому вызовите его в горутине-помощнике, которая по возврату `Wait` сигналит в канал `done`. В `WaitTimeout` ждите в `select` одно из двух: `<-done` (вернуть `true`) или таймер на `d` (вернуть `false`). Счётчик `wg` сами не трогайте — ни `Add`, ни `Done`.

## Подсказка 2

Сигнал помощника — `close(done)`, а не `done <- struct{}{}`: после таймаута из `done` никто не читает, и отправка в небуферизованный канал повисла бы навсегда. Закрытие не блокируется, и помощник завершится, как только счётчик дойдёт до нуля. Таймер — `time.NewTimer(d)` с `defer t.Stop()`.

## Подсказка 3

В `RunAll` выделите `errs := make([]error, len(tasks))` и запускайте `wg.Go(func() { errs[i] = task() })` — каждая горутина пишет только свою ячейку. Затем `if !WaitTimeout(&wg, d) { return nil, false }`: по таймауту задачи ещё пишут в `errs`, и отдать срез наружу — гонка. Иначе `return errs, true`.
