## Подсказка 1

Ведро — буферизованный канал `chan struct{}` ёмкостью `burst`, заполненный в `NewLimiter`. Тогда `Allow` — получение `<-l.tokens` внутри `select` с веткой `default`, а `Wait` — то же получение, но вместо `default` вторая ветка ждёт остановки (см. подсказку 3).

## Подсказка 2

Пополнение — горутина с `time.NewTicker(interval)`. На каждый тик она кладёт токен в канал, но **неблокирующей** отправкой (`select` с `default`): если ведро полное, токен выбрасывается, а горутина не зависает.

## Подсказка 3

Для `Stop` заведите канал `done chan struct{}` и закройте его. Горутина пополнения слушает оба канала:

```go
for {
	select {
	case <-ticker.C:
		// неблокирующая отправка токена
	case <-l.done:
		ticker.Stop()
		return
	}
}
```

Закрытый `done` разбудит и `Wait`: без этой ветки ожидающий после `Stop` висел бы вечно — токенов больше не будет. В ветке `<-l.done` попробуйте забрать остаток через `Allow()`.
