## Подсказка 1

Храните в карте не значения, а функции, которые их возвращают: `map[K]func() (V, error)`. Для нового ключа положите туда `sync.OnceValues(func() (V, error) { return c.load(key) })` — эта обёртка сама вызовет `load` один раз и запомнит оба результата.

## Подсказка 2

Карту защищайте мьютексом, но держите его только пока ищете или добавляете запись. Сам вызов функции из карты делайте после `Unlock` — иначе медленная загрузка одного ключа заблокирует все остальные.

## Подсказка 3

```go
c.mu.Lock()
get, ok := c.entries[key]
if !ok {
	get = sync.OnceValues(func() (V, error) { return c.load(key) })
	c.entries[key] = get
}
c.mu.Unlock()
return get()
```

Паника `load` повторяется при каждом вызове `get` — это поведение `OnceValues`, ничего дописывать не нужно.
