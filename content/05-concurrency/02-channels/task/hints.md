## Подсказка 1

Создайте канал `results := make(chan int)` и для каждого источника запустите горутину, которая вызывает его и отправляет результат в канал.

## Подсказка 2

Сумму считает только вызывающая горутина: она получает из канала ровно `len(sources)` значений. Горутины-отправители не трогают общих переменных — поэтому нет гонки.

## Подсказка 3

Если получить меньше значений, чем отправлено, оставшиеся горутины навсегда застрянут на `results <- v`. Цикл `for range sources { sum += <-results }` получает ровно столько, сколько нужно, и заодно дожидается всех источников.
