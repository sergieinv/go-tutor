## Подсказка 1

В `Bank` храните только каналы, а карту балансов создайте внутри горутины, которую запускает `NewBank`. Горутина в цикле читает запросы и применяет их к карте — по одному.

## Подсказка 2

Чтобы не заводить отдельный тип запроса на каждый метод, отправляйте владельцу функцию: `ops chan func(map[string]int)`. Каждый метод отправляет замыкание, а ответ получает через свой канал, например `resp := make(chan error, 1)`. Проверка баланса и списание внутри одного замыкания выполняются атомарно — между ними владелец не возьмёт другой запрос.

## Подсказка 3

Для `Close` закройте канал запросов — владелец выйдет из `for op := range b.ops` — и дождитесь его завершения через второй канал:

```go
go func() {
	defer close(b.done)
	balances := map[string]int{}
	for op := range b.ops {
		op(balances)
	}
}()
```
