## Подсказка 1

Выделите результат заранее: `out := make([]R, len(in))`. Если воркер знает индекс задачи, он запишет `f(in[i])` прямо в `out[i]` — каждая горутина пишет в свой элемент, гонки нет, и порядок сохраняется сам собой.

## Подсказка 2

Канал задач может нести просто индексы: `jobs := make(chan int)`. Запустите `max(workers, 1)` горутин, каждая делает `for i := range jobs { ... }`. Основная горутина отправляет индексы и закрывает канал.

## Подсказка 3

Чтобы не оставить горутин после возврата, дождитесь воркеров через `sync.WaitGroup`:

```go
for i := range in {
	jobs <- i
}
close(jobs) // воркеры выйдут из range
wg.Wait()
return out
```
