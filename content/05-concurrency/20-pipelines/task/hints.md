## Подсказка 1

Схема та же, что у `merge` из примера: по горутине на каждый вход, `sync.WaitGroup` для учёта и отдельная горутина, которая после `wg.Wait()` закрывает выход. Сама `Merge` только запускает горутины и сразу возвращает канал. Если входов нет, `wg.Wait()` вернётся сразу — канал закроется сам.

## Подсказка 2

`range` по входу и голая отправка `out <- v` не замечают отмены: горутина повиснет либо на входе, который никогда не закроется, либо на выходе, который никто не читает. И чтение, и отправку делайте через `select` со второй веткой `case <-ctx.Done(): return`.

## Подсказка 3

Чтение в `select` — форма `v, ok := <-c`: при `!ok` вход закрыт, горутина выходит. nil-канал пропускайте ещё при запуске (`if c == nil { continue }`) — из него ничего не придёт, а горутина на нём не дала бы выходу закрыться без отмены.
