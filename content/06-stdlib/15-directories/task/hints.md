## Подсказка 1

Обходите дерево через `fs.WalkDir(fsys, ".", fn)`. Первой строкой колбэка обработайте параметр `err` — верните его, чтобы обход прервался. Размер файла даёт `d.Info()`, это `fs.FileInfo` с методом `Size()`.

## Подсказка 2

`fs.SkipDir` возвращайте только когда `d.IsDir()`: для файла он пропустит всех оставшихся соседей по каталогу. Корень приходит с путём `"."` — его не пропускайте. Порядок обхода — по именам внутри каждого каталога, а это не то же самое, что сортировка полных путей (`"a/x"` обходится раньше `"a-b/y"`). Отсортируйте результат в конце.

## Подсказка 3

```go
if d.IsDir() {
	if p != "." && slices.Contains(skipDirs, d.Name()) {
		return fs.SkipDir
	}
	return nil
}
info, err := d.Info()
if err != nil {
	return err
}
if info.Size() >= minSize {
	found = append(found, p)
}
return nil
```

После обхода: при ошибке `return nil, err`, иначе `slices.Sort(found)`.
