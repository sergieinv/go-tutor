## Подсказка 1

Ключи и пропуск пустых значений задаются тегами: `` `json:"tags,omitempty"` ``. Поля выводятся в порядке объявления в структуре, так что `EncodeConfig` — это просто `json.Marshal(c)` с правильными тегами.

## Подсказка 2

`json.Unmarshal` молча игнорирует неизвестные ключи. Строгий разбор — через `json.NewDecoder(bytes.NewReader(data))` и `dec.DisallowUnknownFields()` перед `Decode`. Значение не того типа (`"port":"80"`) `Decode` отвергнет сам.

## Подсказка 3

`Decoder.Decode` читает одно значение и не смотрит, что за ним. Проверьте, что дальше ничего нет: второй вызов должен вернуть ровно `io.EOF`.

```go
if err := dec.Decode(&json.RawMessage{}); err != io.EOF {
	return Config{}, errors.New("лишние данные после объекта")
}
```

Затем проверьте `Name`, подставьте порт по умолчанию и проверьте диапазон.
