`strconv.Atoi` из урока про строки — это сокращение для `ParseInt(s, 10, 0)`. Полные функции разбора принимают ещё два параметра: систему счисления `base` (2–36, или 0 — «по префиксу») и `bitSize` — в какой тип результат должен поместиться. Возвращают они всегда самый широкий тип (`int64`, `uint64`, `float64`), а приведение к `int8` или `uint16` — ваша задача; `bitSize` гарантирует, что оно будет без потерь.

Ошибка разбора — всегда `*strconv.NumError`: в ней имя функции, исходная строка и причина — `strconv.ErrSyntax` (не число) или `strconv.ErrRange` (число, но не влезает). Причину проверяют через `errors.Is`, а не по тексту.

## Как это в C#

- `int.Parse`/`byte.Parse`/`long.Parse` — отдельный метод на каждый тип. В Go одна функция `ParseInt` с `bitSize` 8, 16, 32, 64; для беззнаковых — `ParseUint`.
- `Convert.ToInt32("ff", 16)` → `ParseInt("ff", 16, 32)`. Но в Go основание — любое от 2 до 36, а `base = 0` понимает литералы Go: `0x1F`, `0o17`, `0b101`, `1_000`.
- `FormatException` и `OverflowException` → одна ошибка `*NumError` с `Err == ErrSyntax` или `ErrRange`. При переполнении Go возвращает ещё и ближайшее граничное значение.
- `double.Parse` зависит от `CultureInfo` (`1,5` в русской культуре). `ParseFloat` культур не знает: разделитель — только точка.

## Ловушки

### При переполнении возвращается не ноль

```go
v, err := strconv.ParseInt("300", 10, 8)
fmt.Println(v, err) // 127 strconv.ParseInt: parsing "300": value out of range
```

Если проигнорировать ошибку, программа тихо продолжит с 127. Проверяйте `err` всегда — или осознанно используйте «прижатое» значение.

### Префикс только с `base = 0`

```go
strconv.ParseInt("0x1F", 16, 64) // ошибка: префикс при base 16 не допускается
strconv.ParseInt("0x1F", 0, 64)  // 31
strconv.ParseInt("017", 0, 64)   // 15 — ведущий ноль значит восьмеричное!
```

`base = 0` удобно для литералов, но строка `"017"` из пользовательского ввода станет 15. Для десятичных данных указывайте `10` явно.

### `bitSize` не меняет тип результата

```go
v, _ := strconv.ParseInt("100", 10, 8)
var b int8 = v // не компилируется: v — int64
```

`bitSize` лишь проверяет диапазон. Приведение `int8(v)` после проверки ошибки безопасно.

## Задание

Напишите функцию `ParseSize(s string) (int64, error)`, которая разбирает размер вида `512`, `10K`, `3M`, `2G`.

Требования:

- строка — десятичное число из цифр `0-9` (хотя бы одна цифра, без знака, пробелов, `_` и префиксов), за которым может идти один суффикс: `K` (×1024), `M` (×1024²) или `G` (×1024³); суффикс — только заглавная буква;
- результат — число байт, ведущие нули допустимы (`007K` → 7168);
- любая синтаксическая ошибка (пустая строка, `+5`, `-5`, `1.5K`, `10k`, `10KB`, ` 10`, `K`) — ошибка, для которой `errors.Is(err, strconv.ErrSyntax)`;
- если число или результат умножения не помещается в `int64` (больше `9223372036854775807`) — ошибка, для которой `errors.Is(err, strconv.ErrRange)`;
- при ошибке возвращается 0.
