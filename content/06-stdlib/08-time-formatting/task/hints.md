## Подсказка 1

Раскладки пишутся от эталонной даты `Mon Jan 2 15:04:05 MST 2006`: `02.01.2006` — день.месяц.год, `-07:00` — смещение с двоеточием. Готовая раскладка для строки со смещением — `time.RFC3339`.

## Подсказка 2

`time.Parse` для строки без смещения вернёт UTC — для раскладок 2–4 нужен `time.ParseInLocation(layout, s, loc)`. Он паникует при `loc == nil`, поэтому заранее замените `nil` на `time.UTC`.

## Подсказка 3

Пробуйте раскладки в цикле и возвращайте первый успешный результат; если не подошла ни одна — нулевое время и своя ошибка:

```go
for _, layout := range []string{"2006-01-02 15:04:05", "2006-01-02", "02.01.2006"} {
	if t, err := time.ParseInLocation(layout, s, loc); err == nil {
		return t, nil
	}
}
```

`FormatHuman` — одна строка: `t.Format("02.01.2006 15:04 -07:00")`.
