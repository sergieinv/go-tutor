## Подсказка 1

Для `AddWorkdays` идите по одному календарному дню: `t = t.AddDate(0, 0, step)`, где `step` — `1` или `-1`, и уменьшайте счётчик, только если `t.Weekday()` не суббота и не воскресенье. `AddDate` сохраняет время суток и пояс, а `Add(24 * time.Hour)` в день перевода часов сдвинет время.

## Подсказка 2

Пересечение двух полуинтервалов — от **позднего** из начал до **раннего** из концов. Если конец не позже начала, пересечения нет.

## Подсказка 3

Сравнивайте моменты методами `After` и `Before` — они работают с моментами и не зависят от поясов, в отличие от сравнения `Hour()` или `==`:

```go
start := aStart
if bStart.After(start) {
	start = bStart
}
// ... так же для end, через Before
if !end.After(start) {
	return 0
}
return end.Sub(start)
```
