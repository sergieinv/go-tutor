## Подсказка 1

Каталог: `os.MkdirTemp("", prefix+"*")` — пустой первый аргумент означает `os.TempDir()`. Файл: `os.CreateTemp(dir, "spool-*.tmp")`. Удаление каталога со всем содержимым — `os.RemoveAll`.

## Подсказка 2

Уборку ставьте в `defer` сразу после успешного создания: отложенные вызовы выполняются и при обычном `return`, и при панике. Чтобы вернуть ошибку `RemoveAll`, не затирая ошибку `fn`, сделайте результат именованным и меняйте его в отложенном замыкании только если он ещё `nil`.

## Подсказка 3

```go
defer func() {
	if rerr := os.RemoveAll(dir); rerr != nil && err == nil {
		err = rerr
	}
}()
return fn(dir)
```

В `Spool` — тот же приём: в `defer` при `err != nil` закройте файл и удалите `f.Name()`. Копируйте через `io.Copy(f, r)` и не забудьте проверить ошибку `f.Close()`.
