`//go:embed` — директива компилятору: прочитать файлы при сборке и положить их содержимое в переменную пакета. Тип переменной задаёт форму: `string` или `[]byte` — один файл, `embed.FS` — набор файлов и каталогов по одному или нескольким шаблонам. Результат — один бинарник без внешних файлов: удобно для HTML-шаблонов, SQL-миграций, статики и значений по умолчанию.

Встраивание работает только для переменных уровня пакета, а файлы должны лежать в каталоге пакета или его подкаталогах. `embed.FS` реализует `fs.FS`, так что код поверх него принимает `fs.FS` — и в тестах ему можно подсунуть `fstest.MapFS`.

## Как это в C#

- В .NET файл помечают `<EmbeddedResource>` в `.csproj` и читают через `Assembly.GetManifestResourceStream("MyApp.Data.config.json")` — имя склеивается из пространства имён и пути, ошибки видны только в рантайме. В Go путь пишется в коде, и отсутствующий файл — ошибка **компиляции**.
- Ресурс .NET — поток; `//go:embed` в `string`/`[]byte` даёт готовое значение без чтения и обработки ошибок.
- `embed.FS` похож на `ManifestEmbeddedFileProvider` (пакет Microsoft.Extensions.FileProviders.Embedded) — дерево файлов с каталогами, но встроенное в язык и стандартную библиотеку.
- Встроенные данные только для чтения: у `embed.FS` нет методов записи.

## Ловушки

### Каталог-шаблон пропускает скрытые файлы

```go
//go:embed static
var static embed.FS // static/.well-known/ и static/_redirects не попадут
```

Если шаблон называет каталог, вложенные файлы и каталоги на `.` и `_` исключаются. Префикс `all:` включает их: `//go:embed all:static`. Шаблон-маска вроде `static/*` их тоже захватит, но только на одном уровне.

### Только файлы своего пакета

```go
//go:embed ../config/default.yaml // ошибка: invalid pattern syntax
var cfg []byte
```

`..`, абсолютные пути и файлы из других модулей запрещены. Если данные нужны нескольким пакетам — встройте их в пакет, который лежит рядом с файлами, и экспортируйте переменную или функцию.

### Директива не там или без импорта

```go
package main

//go:embed greeting.txt
var greeting string // ошибка: go:embed requires import "embed"

func load() {
	//go:embed greeting.txt
	var s string // ошибка: go:embed cannot apply to var inside func
}
```

Директива стоит над объявлением `var` уровня пакета (между ними допустимы только пустые строки и комментарии), а пакет `embed` должен быть импортирован — для `string` и `[]byte`, где он не используется по имени, через `import _ "embed"`.

## Задание

Сервис хранит приветствия на разных языках во встроенных файлах `greetings/<lang>.txt`. Напишите функции, которые работают с любым `fs.FS` — в программе им передадут `embed.FS`, а в тестах `fstest.MapFS`:

```go
var ErrBadLang = errors.New("bad language code")

func Greeting(fsys fs.FS, lang string) (string, error)
func Languages(fsys fs.FS) ([]string, error)
```

`Greeting` возвращает текст файла `greetings/<lang>.txt` с обрезанными по краям пробельными символами:

- код языка допустим, если он непустой и состоит только из строчных латинских букв `a`–`z` и дефиса; иначе — `""` и ошибка, для которой `errors.Is(err, ErrBadLang)` (так в путь не попадут `..` и `/`);
- если файла для `lang` нет, используется `greetings/en.txt`; если нет и его — `""` и ошибка, для которой `errors.Is(err, fs.ErrNotExist)`;
- любая другая ошибка чтения возвращается как есть (вместе с `""`), без перехода на `en`.

`Languages` возвращает коды всех языков: имена файлов `greetings/*.txt` без расширения, отсортированные по возрастанию. Файлы в подкаталогах `greetings` и файлы с другими расширениями не учитываются, как и файлы, чьё имя без расширения — недопустимый для `Greeting` код: `greetings/.txt` (пустой код), `greetings/EN.txt`. Если подходящих файлов нет или каталога `greetings` нет вовсе — пустой результат (`nil` допустим) и `nil`-ошибка.
