Строковой интерполяции в Go нет: `$"{name}: {total:F2}"` пишется как `fmt.Sprintf("%s: %.2f", name, total)`. Форматная строка — в стиле `printf` из C: глагол после `%` говорит, *как* показать значение, а флаги, ширина и точность — *сколько места* ему отвести.

Универсальный глагол — `%v`: он печатает любое значение, включая структуры, срезы и map. Если у типа есть метод `String() string` (интерфейс `fmt.Stringer`), `%v`, `%s` и `Println` используют его — это аналог переопределённого `ToString()`.

## Как это в C#

- `$"{x}"` и `string.Format("{0}", x)` → `fmt.Sprintf("%v", x)`. Аргументы позиционные, по порядку; явный номер — `%[2]d`.
- Форматные спецификаторы `{x,8:F3}` и `{s,-10}` → `%8.3f` и `%-10s`. Ширина в `fmt` считается в рунах, а не в байтах.
- `ToString()` → `String() string`. Отдельный «отладочный» вид для `%#v` — метод `GoString()`, примерно как `DebuggerDisplay`.
- Неверный формат в C# — `FormatException` во время выполнения (часть ошибок `string.Format` заранее ловит анализатор CA2241). `fmt` не паникует: вставляет в вывод `%!d(string=x)` или `%!d(MISSING)`. Такие ошибки ловит `go vet` ещё до запуска.

## Ловушки

### `String()` на указателе не вызывается для значения

```go
type temp float64

func (t *temp) String() string { return "..." }

var t temp = 20
fmt.Println(t)  // 20 — у значения нет метода String
fmt.Println(&t) // ...
```

Метод с получателем-указателем есть только у `*temp`. Объявляйте `String` на значении — тогда он работает и для `t`, и для `&t`.

### Бесконечная рекурсия в `String()`

```go
func (u user) String() string {
	return fmt.Sprintf("user %v", u) // %v снова вызовет String → переполнение стека
}
```

Внутри `String` форматируйте поля (`u.Name`), а не всё значение, или приведите к типу без методов: `type plain user; fmt.Sprintf("%v", plain(u))`.

### `Print` и `Println` расставляют пробелы по-разному

```go
fmt.Print("a", 1, 2, "b") // a1 2b — пробел только между не-строками
fmt.Println("a", 1, 2, "b") // a 1 2 b
```

`Println` ставит пробел между всеми операндами, `Print` — только между соседями, которые оба не строки.

## Задание

Напишите тип денег с методом `String` и функцию, печатающую чек.

```go
type Money int64 // сумма в копейках

type Line struct {
	Name  string
	Qty   int
	Price Money // цена за штуку
}
```

Требования к `func (m Money) String() string`:

- формат — рубли, точка и ровно две цифры копеек: `Money(1250)` → `12.50`, `Money(7)` → `0.07`, `Money(0)` → `0.00`;
- отрицательные суммы — со знаком минус: `Money(-5)` → `-0.05`, `Money(-1250)` → `-12.50`.

Требования к `func Receipt(lines []Line) string`:

- для каждой позиции — строка: `Name` по левому краю шириной 12 символов, затем `Qty` по правому краю шириной 4, затем сумма позиции `Price * Qty` (в формате `Money.String`) по правому краю шириной 12, затем `\n` — то есть ровно `fmt.Sprintf("%-12s%4d%12v\n", ...)`;
- ширина считается в символах (рунах); длинные значения не обрезаются;
- последняя строка — `TOTAL` по левому краю шириной 16 и общая сумма по правому краю шириной 12, затем `\n`;
- для пустого или `nil` списка чек состоит только из строки `TOTAL` с суммой `0.00`.

Пример: `Receipt([]Line{{"кофе", 2, 15000}})` →

```
кофе           2      300.00
TOTAL                 300.00
```
