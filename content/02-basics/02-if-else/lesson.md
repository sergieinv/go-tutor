`if` в Go выглядит как в C#, только без скобок вокруг условия, а фигурные скобки обязательны всегда — даже для одной строки. Условие должно иметь тип `bool`: `if n` для числа или `if ptr` для указателя не скомпилируется.

Главная особенность — init-выражение: `if v, err := f(); err != nil { ... }`. Переменные из него живут только внутри `if` и всех его веток `else`. Тернарного оператора `?:` нет совсем — вместо него пишут обычный `if` или берут встроенные `min` и `max`.

## Как это в C#

- `x = a > b ? a : b` в Go не существует. Пишут `x := b; if a > b { x = a }` или `x := max(a, b)`.
- В C# `if (int.TryParse(s, out var n))` объявляет `n` во внешней области — она видна и после `if`. В Go переменная из init-выражения видна только в `if` и его `else`.
- `if (x) Foo();` без фигурных скобок в Go — синтаксическая ошибка. Зато споров о стиле нет: `gofmt` расставит всё одинаково.
- Неявных приведений к `bool` нет ни в C#, ни в Go, но в Go нет и `null`-проверок через `?.` и `??` — сравнивают явно: `if p != nil`.

## Ловушки

### Переменная из init-выражения не видна после `if`

```go
if n, err := strconv.Atoi(s); err != nil {
	return err
}
fmt.Println(n) // ошибка компиляции: undefined: n
```

Если значение нужно дальше, объявите его до `if`: `n, err := strconv.Atoi(s)`, а затем `if err != nil { return err }`.

### `:=` внутри ветки создаёт новую переменную

```go
var err error
if s != "" {
	n, err := strconv.Atoi(s) // новая err, внешняя не меняется
	fmt.Println(n, err)
}
fmt.Println(err) // <nil> — даже если Atoi вернул ошибку
```

Внутри блока `:=` объявляет новые переменные, которые затеняют внешние. Чтобы записать во внешнюю `err`, объявите `n` отдельно и используйте `=`.

### `else` переносить на новую строку нельзя

```go
if x > 0 {
	fmt.Println("pos")
}
else { // syntax error: unexpected else
	fmt.Println("non-pos")
}
```

Компилятор сам ставит `;` в конце строки, которая заканчивается на `}`. Поэтому `else` всегда пишут на одной строке с закрывающей скобкой: `} else {`.

## Задание

Напишите функцию `BMICategory(weight, height string) string`. Она разбирает вес в килограммах и рост в метрах из строк, считает индекс массы тела `weight / (height * height)` и возвращает категорию.

Требования:

- если любую из строк не удаётся разобрать через `strconv.ParseFloat(s, 64)` или значение не больше нуля — вернуть `"invalid"`;
- индекс меньше 18.5 — `"underweight"`;
- от 18.5 (включительно) до 25 — `"normal"`;
- от 25 (включительно) до 30 — `"overweight"`;
- 30 и больше — `"obese"`.
