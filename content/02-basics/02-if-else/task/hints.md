## Подсказка 1

Сначала разберитесь с некорректным вводом и сразу возвращайте `"invalid"`, а категорию считайте в конце — так основной путь останется без вложенности.

## Подсказка 2

Значения веса и роста нужны после проверки ошибки, поэтому init-выражение `if w, err := ...; err != nil` не подойдёт: `w` не будет видна после `if`. Объявите `w, err := strconv.ParseFloat(weight, 64)` отдельной строкой.

## Подсказка 3

Проверку объединяйте: `if err != nil || w <= 0 { return "invalid" }`. Категории — цепочка `if bmi < 18.5 ... else if bmi < 25 ... else if bmi < 30 ...`, а всё остальное — `"obese"`. Строгое `<` как раз даёт включительные нижние границы.
