## Подсказка 1

Базовый случай у всех трёх функций один: `n == nil`. Для пустого поддерева ответ известен сразу — 0 для суммы и глубины, ничего для обхода.

## Подсказка 2

Рекурсивный шаг: результат для узла собирается из результатов для `n.Left` и `n.Right`. Сумма — `n.Val` плюс суммы поддеревьев, глубина — `1 + max(...)` глубин поддеревьев.

## Подсказка 3

Для `InOrder` удобно рекурсивное замыкание, которое дописывает в общий срез: объявите `out := []int{}` (не `nil`), затем `var walk func(*Node)` и присвойте `walk` литерал, который вызывает `walk(n.Left)`, делает `append`, затем `walk(n.Right)`.
