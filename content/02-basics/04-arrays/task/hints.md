## Подсказка 1

Массивы можно возвращать из функции и сравнивать через `==` — результат `Rotate` удобно собирать в новой переменной `var r [3][3]byte` и вернуть её целиком.

## Подсказка 2

При повороте по часовой стрелке строка `i` становится столбцом `2-i`, а столбец `j` — строкой `j`. Писать результат в `b` нельзя: вы затрёте значения, которые ещё не прочитали.

## Подсказка 3

`r[j][2-i] = b[i][j]` в двойном цикле `for i := range 3 { for j := range 3 { ... } }`. Для `Winner` проверьте 3 строки, 3 столбца и 2 диагонали: знак `c` — не `'.'` и совпадает с двумя другими клетками линии.
