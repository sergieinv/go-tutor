Массив в Go — последовательность элементов фиксированной длины: `[5]int`. Длина — часть типа, поэтому `[3]int` и `[4]int` — два разных, несовместимых типа. Изменить длину массива нельзя.

Главное отличие от C#: массив — **значение**, а не ссылка. Присваивание и передача в функцию копируют все элементы, а `==` сравнивает содержимое. В повседневном коде массивы встречаются редко — чаще используют срезы, которые построены поверх массивов (о них следующий урок). Но чтобы понять срезы, нужно понять массив под ними.

## Как это в C#

- `int[]` в C# — ссылочный тип: `b = a` даёт две ссылки на один объект. В Go `b := a` копирует все элементы, и изменения `b` не видны в `a`.
- Длина C#-массива задаётся при создании и не входит в тип. В Go `[3]int` и `[4]int` — разные типы, их нельзя присвоить друг другу.
- `a == b` в C# сравнивает ссылки, содержимое сравнивают через `SequenceEqual`. В Go `==` сравнивает элементы, а массив можно сделать ключом map.
- Ближе всего к массиву Go — `[InlineArray]`-структура из C# 12: фиксированный размер и семантика значения.

## Ловушки

### Функция получает копию массива

```go
func reset(a [3]int) { a[0] = 0 }

a := [3]int{1, 2, 3}
reset(a)
fmt.Println(a) // [1 2 3] — изменилась копия
```

Чтобы функция меняла массив, передают указатель `*[3]int` или срез `a[:]`. А для большого массива копирование при каждом вызове ещё и дорого.

### `[]int{...}` — это срез, а `[...]int{...}` — массив

```go
a := [...]int{1, 2, 3} // массив [3]int, длину посчитал компилятор
s := []int{1, 2, 3}    // срез — совсем другой тип
b := a                 // копия элементов
t := s                 // общий массив
```

Разница в одних скобках, а поведение при присваивании противоположное.

### `range` по массиву обходит его копию

```go
a := [3]int{1, 2, 3}
for i, v := range a {
	if i == 0 {
		a[2] = 100
	}
	fmt.Print(v, " ") // 1 2 3 — изменение не видно
}
```

Выражение `range` вычисляется один раз, и для массива это копия. Со срезом тот же код напечатал бы `1 2 100`.

## Задание

Поле крестиков-ноликов — массив `[3][3]byte`, клетки содержат `'X'`, `'O'` или `'.'`.

Напишите две функции:

- `Rotate(b [3][3]byte) [3][3]byte` возвращает поле, повёрнутое на 90° по часовой стрелке: верхняя строка становится правым столбцом. Исходное поле не меняется.
- `Winner(b [3][3]byte) byte` возвращает `'X'` или `'O'`, если у игрока три одинаковых знака в строке, столбце или на диагонали, иначе `'.'`. Гарантируется, что выигрышные линии есть не больше чем у одного игрока.
