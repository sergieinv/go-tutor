Анонимная функция (`func(...) {...}` без имени) может обращаться к переменным окружающей функции. Такая функция — замыкание: она захватывает **саму переменную**, а не её значение на момент создания. Если переменная потом меняется, замыкание видит новое значение; если замыкание её меняет, это видно снаружи.

Захваченная переменная живёт столько, сколько живёт замыкание, — даже после возврата из функции, где её объявили. Так делают счётчики, генераторы и функции с состоянием без отдельного класса.

## Как это в C#

- Лямбды C# тоже захватывают переменные, а не значения: компилятор переносит их в скрытый класс-замыкание. В Go то же самое делает escape analysis — переменная переезжает в кучу.
- В C# 5 изменили `foreach`: переменная цикла стала своей на каждой итерации. Обычный `for (int i = ...)` в C# так и остался с одной переменной на весь цикл. В Go с версии 1.22 своя переменная на каждой итерации у **обоих** видов цикла — и `for range`, и `for i := 0; ...`.
- Делегат в C# — объект, который можно сравнить и отписать (`-=`). Функцию в Go сравнить нельзя — только с `nil`.

## Ловушки

### Замыкание видит последнее значение переменной

```go
x := 1
f := func() int { return x }
x = 2
fmt.Println(f()) // 2, а не 1
```

Нужно значение на момент создания — скопируйте его в новую переменную или передайте параметром.

### Переменная цикла до Go 1.22

```go
var fs []func()
for i := 0; i < 3; i++ {
	fs = append(fs, func() { fmt.Print(i) })
}
for _, f := range fs {
	f()
}
// Go 1.22+: 012. До 1.22 (или с go 1.21 в go.mod): 333
```

Поведение зависит от версии в `go.mod`, а не от версии компилятора. В старом коде вы встретите строки `i := i` перед замыканием — это обход старой семантики, в новом коде он не нужен.

### Захват в горутинах

```go
count := 0
for range 1000 {
	go func() { count++ }() // гонка данных: все горутины пишут в одну count
}
```

Замыкание делит переменную со всеми, кто её захватил, включая горутины. Синхронизацию разберём в модуле о конкурентности; пока запомните, что `go run -race` такое ловит.

## Задание

Напишите две функции:

- `Counter(start, step int) func() int` — возвращает функцию, которая при первом вызове возвращает `start`, при втором — `start+step`, и так далее. Каждый вызов `Counter` даёт независимый счётчик.
- `Memo(f func(int) int) (call func(int) int, calls func() int)` — оборачивает `f` кэшем: `call(n)` вычисляет `f(n)` только при первом запросе этого `n`, а дальше возвращает сохранённый результат. `calls()` сообщает, сколько раз была реально вызвана `f`.
