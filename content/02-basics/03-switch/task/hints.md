## Подсказка 1

`Season` — обычный `switch month` с несколькими значениями в каждом `case`. `StatusClass` удобнее записать как `switch` без выражения: каждый `case` — отдельное условие на диапазон.

## Подсказка 2

Ветки проверяются сверху вниз, и выполняется первая подходящая. Если поставить диапазон 400–499 раньше проверки на 429, до неё дело не дойдёт. Частные случаи — выше общих.

## Подсказка 3

```go
switch {
case code == 429:
	return "rate limited"
case code >= 100 && code < 200:
	return "informational"
// ... остальные диапазоны
default:
	return "unknown"
}
```

В `Season` то же самое делает `default: return "invalid"`.
