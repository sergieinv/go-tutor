`switch` в Go выполняет ровно одну подходящую ветку и выходит — `break` в конце ветки не нужен. Если нужно провалиться в следующую ветку, это пишут явно словом `fallthrough`. Несколько значений перечисляют через запятую в одном `case`.

Значения в `case` не обязаны быть константами: это любые выражения, которые сравниваются с выражением `switch` сверху вниз до первого совпадения. А `switch` без выражения — это просто аккуратная запись цепочки `if / else if`: каждый `case` — отдельное условие.

Есть ещё type switch — `switch v := x.(type)` — для ветвления по динамическому типу интерфейса. Его разберём в уроке про значения интерфейсов (03-types/04-interface-values).

## Как это в C#

- В C# каждую ветку обязательно завершают `break` (или `return`/`goto`), иначе ошибка компиляции. В Go ветка завершается сама.
- Общее тело для нескольких значений в C# — подряд идущие метки `case 1: case 2:`. В Go так нельзя: пустой `case 1:` означает «ничего не делать». Пишут `case 1, 2:`.
- Метки `case` в C# — константы или паттерны. В Go — любые выражения, включая вызовы функций, а `switch { case x > 0: ... }` заменяет паттерны с `when`.
- `goto case` из C# в Go — `fallthrough`, но только в следующую ветку и без проверки её условия.

## Ловушки

### Пустой `case` не проваливается в следующий

```go
switch day {
case "sat":           // ничего не делает
case "sun":
	fmt.Println("выходной") // только для "sun"
}
```

Привычка из C# с подряд идущими метками здесь молча ломает логику. Правильно: `case "sat", "sun":`.

### `fallthrough` не проверяет условие следующей ветки

```go
switch x := 5; {
case x > 0:
	fmt.Println("положительное")
	fallthrough
case x > 100:
	fmt.Println("больше ста") // напечатается, хотя 5 < 100
}
```

`fallthrough` безусловно передаёт управление в тело следующего `case`. Он должен быть последним оператором ветки и не может стоять в последней ветке.

### `break` внутри `switch` не выходит из цикла

```go
for _, cmd := range cmds {
	switch cmd {
	case "stop":
		break // выходит только из switch
	}
}
```

Чтобы прервать цикл, поставьте на него метку и пишите `break loop`, или вынесите цикл в функцию и используйте `return`.

## Задание

Напишите две функции.

`Season(month int) string` возвращает время года по номеру месяца: 12, 1, 2 — `"winter"`; 3, 4, 5 — `"spring"`; 6, 7, 8 — `"summer"`; 9, 10, 11 — `"autumn"`. Для любого другого числа — `"invalid"`.

`StatusClass(code int) string` возвращает класс HTTP-кода:

- 100–199 — `"informational"`, 200–299 — `"success"`, 300–399 — `"redirect"`;
- 400–499 — `"client error"`, но для кода 429 — `"rate limited"`;
- 500–599 — `"server error"`;
- любой другой код — `"unknown"`.
