## Подсказка 1

Разбор в два уровня: сначала `strings.Split(s, ";")` на пары, затем каждую пару — на ключ и значение. Пробелы снимает `strings.TrimSpace`, регистр — `strings.ToLower`.

## Подсказка 2

`strings.Cut(pair, "=")` делит строку по первому `=` и возвращает третьим результатом, нашёлся ли разделитель. Значение переводите в число через `strconv.Atoi` — он вернёт ошибку для `"1.5"`, `"two"` и `"1=2"`.

## Подсказка 3

Создайте map через `make` до цикла — тогда для пустой строки вернётся пустая, а не `nil` map. Пустую после `TrimSpace` пару пропускайте через `continue`. При любой ошибке возвращайте `nil, err` сразу, не накапливая частичный результат.
