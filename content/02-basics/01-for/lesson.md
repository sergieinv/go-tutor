В Go одно ключевое слово для циклов — `for`. Нет ни `while`, ни `do-while`, ни отдельного `foreach`: все они — формы `for`. Классический цикл с тремя частями, цикл с одним условием (это и есть «while»), бесконечный цикл без условия и `for ... range` для обхода коллекций и чисел.

Скобки вокруг заголовка не пишут, фигурные скобки тела обязательны. Для выхода из вложенных циклов есть метки: `break outer` и `continue outer`.

## Как это в C#

- `while (cond)` → `for cond {}`, `while (true)` → `for {}`. Аналога `do-while` нет: пишут `for { ...; if !cond { break } }`.
- `for (int i = 0; i < 10; i++)` → `for i := 0; i < 10; i++` — без скобок. А `Enumerable.Range(0, 10)` в `foreach` заменяет `for i := range 10`.
- В C# переменная классического `for` одна на весь цикл, и лямбды видят её последнее значение. В Go с версии 1.22 у каждой итерации своя копия переменной — и в `for i := 0; ...`, и в `range`.
- Выйти из вложенного цикла в C# можно через `goto` или флаг. В Go есть метки: `break outer` выходит сразу из внешнего цикла.

## Ловушки

### `break` внутри `switch` не выходит из цикла

```go
for i := range 5 {
	switch i {
	case 2:
		break // выходит только из switch, цикл идёт дальше
	}
	fmt.Print(i, " ") // 0 1 2 3 4
}
```

`break` относится к ближайшему `for`, `switch` или `select`. Чтобы выйти из цикла, поставьте на него метку: `loop: for ...` и `break loop`.

### Семантика переменной цикла зависит от `go.mod`

```go
var fns []func()
for i := 0; i < 3; i++ {
	fns = append(fns, func() { fmt.Print(i) })
}
for _, f := range fns {
	f() // 012 при go >= 1.22 в go.mod, 333 — при более старой версии
}
```

Новая семантика включается строкой `go 1.22` (или выше) в `go.mod`. В старом модуле замыкания видят одну общую переменную.

## Задание

Напишите две функции.

`Primes(n int) []int` возвращает все простые числа, меньшие `n`, по возрастанию.

- Для `n <= 2` возвращается пустой срез (длины 0).
- Используйте вложенный цикл и `continue` с меткой: как только найден делитель, переходите к следующему кандидату. Это рекомендация способа: тесты проверяют только результат.

`CollatzSteps(n int) int` считает, за сколько шагов последовательность Коллатца дойдёт от `n` до 1: чётное число делится на 2, нечётное заменяется на `3n+1`.

- `CollatzSteps(1)` равно 0, `CollatzSteps(6)` равно 8.
- Для `n <= 0` функция возвращает `-1`.
