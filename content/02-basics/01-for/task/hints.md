## Подсказка 1

`Primes` — два вложенных цикла: внешний перебирает кандидатов от 2 до `n-1`, внутренний ищет делитель. `CollatzSteps` — цикл с одним условием `for n != 1`, то есть «while».

## Подсказка 2

Найдя делитель, внутренний цикл должен не просто остановиться, а сразу перейти к следующему кандидату — иначе после него выполнится `append`. Для этого нужна метка на внешнем цикле и `continue` с этой меткой.

## Подсказка 3

```go
candidates:
	for i := 2; i < n; i++ {
		for d := 2; d*d <= i; d++ {
			if i%d == 0 {
				continue candidates
			}
		}
		primes = append(primes, i)
	}
```

Начните с `primes := []int{}`, а в `CollatzSteps` первым делом верните `-1` для `n <= 0` — иначе цикл никогда не дойдёт до 1.
