## Подсказка 1

Создайте map через `make(map[string]int)` до цикла — тогда для текста без слов вернётся пустая, но пригодная для записи map. Благодаря нулевому значению счётчик пишется одной строкой: `counts[w]++`.

## Подсказка 2

Порядок обхода map случаен, поэтому результат `MostFrequent` нужно упорядочить явно. Проще всего обходить не саму map, а отсортированные ключи: `slices.Sorted(maps.Keys(counts))`.

## Подсказка 3

Идите по отсортированным ключам и храните текущий максимум `best` и срез `words`. Если счётчик больше `best` — начните срез заново с этого слова, если равен — допишите слово. Начните с `words := []string{}`, чтобы для пустой map вернуть пустой срез, а не `nil`.
