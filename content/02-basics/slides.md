# Базовый синтаксис

Обзор модуля для показа команде: чем Go отличается от C# на уровне самых простых конструкций.

---

## Один цикл, zero values, без null

- `for` — единственный цикл: и `while`, и `foreach` через `range`.
- У каждой переменной есть нулевое значение: `0`, `""`, `false`, `nil`. Неинициализированных переменных нет.
- Неиспользуемая переменная или импорт — ошибка компиляции, а не предупреждение.

---

## Срез — не `List<T>`

Срез — маленькая структура из трёх полей: указатель на массив, `len` и `cap`. Присваивание копирует только эти три поля, массив остаётся общим.

```go
a := []int{1, 2, 3}
b := a      // тот же массив
b[0] = 100  // a[0] тоже 100
```

## Что запомнить

- Результат `append` всегда присваивают: `s = append(s, x)`.
- Независимую копию делает `slices.Clone` или `s[:len(s):len(s)]` перед `append`.
- Строка в Go — байты UTF-8, `len("ё")` равен 2.
