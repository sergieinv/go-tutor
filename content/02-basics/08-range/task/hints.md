## Подсказка 1

`FirstUnique` удобно решать в два прохода `range` по строке: первый считает руны в `map[rune]int`, второй ищет первую руну со счётчиком 1. `ApplyDiscount` ничего не возвращает — менять нужно сами элементы среза.

## Подсказка 2

Индекс, который даёт `range` по строке, — это уже байтовое смещение руны. Не считайте позицию своим счётчиком итераций: для кириллицы и эмодзи он даст номер руны, а не байт.

## Подсказка 3

В `ApplyDiscount` пишите `for i := range items { items[i].Price = items[i].Price * (100 - pct) / 100 }`. Вариант `for _, it := range items { it.Price = ... }` меняет копию, и срез останется прежним.
