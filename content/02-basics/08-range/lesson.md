`for ... range` — это `foreach` в Go. Он обходит срезы, массивы, строки, map, каналы, целые числа и функции-итераторы. Для каждой итерации выдаёт до двух значений: для среза — индекс и элемент, для строки — байтовый индекс и руну, для map — ключ и значение, для числа — одно значение от 0 до n-1.

Две вещи нужно запомнить. Переменная элемента — копия: изменение `v` не меняет коллекцию. И выражение после `range` вычисляется один раз до начала цикла: длина среза фиксируется, а массив копируется целиком.

Обход каналов разберём в модуле о конкурентности, а range по функциям — `iter.Seq` и собственные итераторы — в уроке 03-types/09-iterators.

## Как это в C#

- `foreach (var x in list)` → `for _, x := range list`. Индекс приходит бесплатно, а если он не нужен, его заменяют на `_`.
- Изменить `List<T>` внутри `foreach` нельзя — будет `InvalidOperationException`. В Go можно: `append` внутри `range` не ломает цикл, но и новые элементы цикл не увидит.
- `foreach` по `string` в C# даёт `char` — UTF-16 единицы. `range` по строке Go даёт `rune` (кодовую точку Unicode), а индекс — смещение в байтах UTF-8.
- `foreach (var item in items) item.Count++` для класса меняет объект. В Go элемент среза структур копируется в `v`, и менять нужно через индекс: `items[i].Count++`.

## Ловушки

### `v` — копия элемента

```go
type item struct{ qty int }
items := []item{{1}, {2}}
for _, it := range items {
	it.qty *= 10 // меняется копия
}
fmt.Println(items) // [{1} {2}]
for i := range items {
	items[i].qty *= 10 // меняется элемент
}
```

Для больших структур копия на каждой итерации ещё и стоит времени — обход по индексу решает обе проблемы.

### Индекс в строке — байты, а не символы

```go
for i, r := range "мир" {
	fmt.Print(i, ":", string(r), " ") // 0:м 2:и 4:р
}
fmt.Println(len("мир")) // 6 — байты, а не руны
```

Кириллица в UTF-8 занимает по 2 байта, эмодзи — по 4. Число рун — `utf8.RuneCountInString(s)`, а индекс `i` годится только для `s[i:]`.

### `append` во время `range` не продлевает цикл

```go
s := []int{1, 2, 3}
for _, v := range s {
	s = append(s, v) // цикл всё равно сделает 3 итерации
}
fmt.Println(s) // [1 2 3 1 2 3]
```

Длина берётся один раз до начала цикла. Но запись в ещё не пройденный элемент существующего массива цикл увидит — `range` по срезу не копирует данные, в отличие от `range` по массиву.

## Задание

Напишите две функции.

`FirstUnique(s string) (rune, int)` возвращает первую руну, которая встречается в строке ровно один раз, и её **байтовый** индекс в `s`. Если такой руны нет (в том числе для пустой строки) — вернуть `0, -1`.

`ApplyDiscount(items []Item, pct int)` уменьшает цену каждого товара на `pct` процентов прямо в переданном срезе: новая цена — `Price * (100 - pct) / 100` с целочисленным делением. Тип `Item` уже объявлен в шаблоне: `type Item struct { Name string; Price int }`. Гарантируется, что `0 <= pct <= 100`.
