## Подсказка 1

Через указатель пишут с разыменованием: `*a = ...`. Присваивание `a = b` поменяло бы только локальные копии указателей. Не забудьте проверить `nil` до разыменования.

## Подсказка 2

В Go есть множественное присваивание: `*a, *b = *b, *a` меняет значения без временной переменной. Для `MaxPtr` найдите индекс максимума одним проходом; сравнение `>` (а не `>=`) оставит первый из равных.

## Подсказка 3

Не возвращайте `&v`, где `v` — переменная цикла `range`: это адрес копии, а не элемента. Верните `&s[best]` — адрес элемента массива под срезом. Пустой срез обработайте в начале: `if len(s) == 0 { return nil }`.
