В Go всё передаётся по значению: аргумент функции — копия, присваивание — копия. Чтобы функция могла изменить переменную вызывающего кода, ей передают указатель: `&x` берёт адрес переменной, `*p` читает или пишет значение по адресу.

Указатели в Go безопасные: арифметики нет, память освобождает сборщик мусора, а адрес локальной переменной можно спокойно вернуть из функции — компилятор сам решит, разместить её в куче или на стеке (escape analysis, подробно — в модуле 11). Разыменование `nil` — паника, а не повреждение памяти.

## Как это в C#

- В C# классы — ссылочные типы, структуры — значимые. В Go такого деления нет: любой тип, включая структуру, копируется при присваивании, а разделяемость задаётся явно — указателем `*T`.
- `ref` и `out` в C# — модификаторы параметра (`Inc(ref x)`), а ссылку нельзя положить в поле класса или в коллекцию. Указатель Go — обычное значение: `inc(&x)` создаёт его явно, и его можно хранить в поле, срезе, map или вернуть из функции.
- Указатели в `unsafe`-коде C# поддерживают арифметику (`p++`). В Go `p++` не скомпилируется — для низкоуровневой работы есть пакет `unsafe`.
- `NullReferenceException` в Go — паника `invalid memory address or nil pointer dereference`. Как и в C#, это ошибка программы, а не способ управления потоком.

## Ловушки

### Указатель на элемент среза после `append`

```go
s := []int{1, 2, 3}
p := &s[0]
s = append(s, 4) // места не было — новый массив
*p = 100
fmt.Println(s[0]) // 1: p указывает в старый массив
```

Не храните указатели на элементы среза, который растёт. Храните индекс или срез указателей `[]*T`.

### nil-указатель

```go
var p *int
fmt.Println(p == nil) // true
fmt.Println(*p)       // panic: runtime error: invalid memory address or nil pointer dereference
```

Нулевое значение указателя — `nil`. Проверяйте его там, где указатель может не прийти, например у необязательных полей.

### Переприсваивание параметра-указателя ничего не меняет снаружи

```go
func reset(p *int) {
	p = new(int) // меняется локальная копия указателя
}
```

Указатель тоже передаётся по значению. Чтобы изменить значение — пишите `*p = 0`; чтобы изменить сам указатель вызывающего кода, нужен `**int` (так делают редко — обычно возвращают новое значение).

## Задание

Напишите две функции:

- `Swap(a, b *int)` — меняет местами значения, на которые указывают `a` и `b`. Если хотя бы один указатель `nil`, функция ничего не делает (и не паникует).
- `MaxPtr(s []int) *int` — возвращает указатель на максимальный элемент **самого среза** (не на копию), чтобы через него можно было изменить элемент. Если максимумов несколько — на первый. Для пустого среза возвращает `nil`.
