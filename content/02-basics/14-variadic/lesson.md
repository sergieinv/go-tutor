Последний параметр функции может принимать любое число аргументов: `func sum(nums ...int) int`. Внутри функции `nums` — обычный срез `[]int`. Если аргументов не передали, срез равен `nil`.

Если значения уже лежат в срезе, его «разворачивают» при вызове: `sum(s...)`. Срез при этом не копируется: функция получает **тот же** массив, что и вызывающий код, и может его изменить — так же, как метод с `params` в C# получает переданный ему готовый массив. Так устроены `fmt.Println(a ...any)` и `append(s []T, x ...T)`.

## Как это в C#

- `params int[] nums` → `nums ...int`. Внутри — срез, а не массив, и при отсутствии аргументов он `nil`, а не пустой массив.
- В C# передать массив в `params` можно напрямую: `Sum(arr)`. В Go нужен явный разворот `Sum(s...)` — без `...` срез не подойдёт по типу.
- И в C#, и в Go переданный целиком массив/срез не копируется. Смешать нельзя ни там, ни там: `sum(1, s...)` в Go, как и `Sum(1, arr)` в C#, не скомпилируется — либо отдельные значения, либо один срез.
- `params object[]` → `...any`. Значения упаковываются в интерфейсы, как боксинг в `object`.

## Ловушки

### Функция меняет срез вызывающего кода

```go
func normalize(xs ...int) {
	for i := range xs {
		xs[i] = max(xs[i], 0)
	}
}

s := []int{-1, 5}
normalize(s...)
fmt.Println(s) // [0 5] — исходный срез изменён
```

С отдельными аргументами `normalize(-1, 5)` компилятор создаёт новый срез, и вызывающий код ничего не замечает. Если функция меняет variadic-параметр, работайте с копией: `xs = slices.Clone(xs)`.

### `[]string` не подходит к `...any`

```go
names := []string{"a", "b"}
fmt.Println(names...) // ошибка: cannot use names (variable of type []string) as []any value
```

`[]string` и `[]any` — разные типы с разным устройством в памяти. Нужен цикл, который сложит элементы в `[]any`.

### `append` к variadic-срезу может испортить чужие данные

`append(xs, v)` внутри функции при свободной ёмкости запишет в массив вызывающего кода — та же ловушка общего массива, что в уроке о срезах.

## Задание

Напишите две функции:

- `Sum(nums ...int) int` — сумма аргументов; без аргументов — 0.
- `Clamp(lo, hi int, nums ...int) []int` — возвращает **новый** срез, где каждое число ограничено отрезком `[lo, hi]`. Переданный срез (в том числе при вызове `Clamp(lo, hi, s...)`) не должен меняться. Без аргументов возвращается пустой срез длины 0 (не `nil`). Если `lo > hi`, функция паникует.
