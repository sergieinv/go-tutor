Срез (`[]T`) — главная коллекция Go. Выглядит как `List<T>`, но устроен иначе: это маленькая структура из трёх полей — указатель на элемент массива, длина `len` и ёмкость `cap`. Сам массив живёт отдельно, и несколько срезов могут смотреть в один и тот же массив.

Из этого следует почти всё поведение срезов: присваивание копирует только заголовок, срез среза не копирует данные, а `append` иногда пишет в старый массив, а иногда выделяет новый.

## Как это в C#

- `List<T>` — ссылочный тип: две переменные указывают на один объект. Срез — значение: копируется заголовок (ptr, len, cap), но массив под ним общий.
- `list.GetRange(i, n)` копирует элементы. `s[i:j]` ничего не копирует — ближайший аналог в C# — `Span<T>` или `ArraySegment<T>`.
- `list.Add(x)` меняет список на месте. `append(s, x)` возвращает новый заголовок, и его нужно присвоить: `s = append(s, x)`.
- Пустой `List<T>` и `null` — разные вещи. `nil`-срез ведёт себя как пустой: `len` равен 0, `range` и `append` работают.

## Под капотом

Заголовок среза — это `struct { ptr *T; len, cap int }`. Пока `len < cap`, `append` кладёт элемент в тот же массив и возвращает заголовок с увеличенной длиной. Когда места нет, рантайм выделяет новый массив (для небольших срезов — примерно вдвое больше), копирует элементы и возвращает заголовок, указывающий уже на новый массив. Старые срезы продолжают смотреть в старый массив.

## Ловушки

### `append` в общий массив

Два `append` к одному срезу с запасом ёмкости пишут в одну и ту же ячейку:

```go
a := make([]int, 3, 4)
b := append(a, 1)
c := append(a, 2)
fmt.Println(b[3], c[3]) // 2 2
```

Если результат `append` должен быть независимым, ограничьте ёмкость: `a[:len(a):len(a)]` — тогда `append` будет вынужден выделить новый массив.

### Маленький срез держит большой массив

```go
data := readFile()      // 100 МБ
header := data[:64]     // держит в памяти все 100 МБ
header = slices.Clone(data[:64]) // копия на 64 байта
```

Пока жив `header`, сборщик мусора не может освободить исходный массив.

### `range` отдаёт копию элемента

```go
for _, it := range items {
	it.Count++ // меняется копия, items не изменится
}
for i := range items {
	items[i].Count++ // так правильно
}
```

## Задание

Напишите функцию `Chunk(s []int, n int) [][]int`, которая делит срез на последовательные части длиной `n` (последняя часть может быть короче).

Требования:

- части не копируют данные — они ссылаются на массив исходного среза;
- `append` к любой части не должен портить соседние части и исходный срез;
- для пустого `s` возвращается пустой результат;
- при `n <= 0` функция паникует.
