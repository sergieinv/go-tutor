## Подсказка 1

Результаты функции перечислены в сигнатуре: `return lo, hi, true`. Для `ParsePoint` разбейте строку `strings.Split(s, ",")` и проверьте, что частей ровно две.

## Подсказка 2

Каждую часть очистите `strings.TrimSpace` и разберите `strconv.Atoi` — он сам вернёт ошибку для `"a"`, `"1.5"` и пустой строки. Ошибку сразу возвращайте наверх: `if err != nil { return 0, 0, err }`.

## Подсказка 3

Осторожно с именованными результатами: если разобрать первую часть прямо в `x`, а вторая окажется некорректной, голый `return` вернёт уже заполненный `x`. Пишите `return 0, 0, err` явно. В `MinMax` начните с `nums[0]` и пройдите по остальным, обновляя `lo` и `hi` встроенными `min` и `max`.
