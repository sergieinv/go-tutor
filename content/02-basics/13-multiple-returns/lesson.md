Функция в Go может вернуть несколько значений: `func divmod(a, b int) (int, int)`. На этом построены две главные идиомы языка. `(value, error)` — вместо исключений: последний результат — ошибка, `nil` значит успех. `(value, ok)` — вместо `TryGet`: второй результат сообщает, нашлось ли значение.

Ненужный результат отбрасывают пустым идентификатором `_` — компилятор не даст просто забыть про него, если присваиваете хотя бы один. Результаты можно назвать: тогда они становятся переменными, инициализированными нулевыми значениями, и голый `return` возвращает их текущие значения.

## Как это в C#

- `int.TryParse(s, out var n)` → `n, err := strconv.Atoi(s)`. Вместо out-параметров — второй результат, и вызов не прячет, что функция что-то возвращает.
- Кортежи `(int q, int r) DivMod(...)` похожи на несколько результатов, но в Go это не тип: результат нельзя положить в одну переменную — только разобрать на столько переменных, сколько значений.
- `dict.TryGetValue(k, out var v)` → `v, ok := m[k]`. Та же форма «запятая-ok» у приведения типа и чтения из канала.
- Исключение «пробивает» стек само. Ошибку в Go нужно явно вернуть наверх: `if err != nil { return 0, err }`.

## Ловушки

### Голый `return` в длинной функции

```go
func parse(s string) (n int, err error) {
	n, err = strconv.Atoi(s)
	if err != nil {
		return // что именно вернулось? нужно смотреть наверх
	}
	// ... 40 строк ...
	return
}
```

Голый `return` хорош в коротких функциях. В длинных читателю приходится отслеживать, что лежит в именованных результатах к этому моменту. Пишите `return n, err` явно.

### Затенение именованного результата

```go
func load() (err error) {
	if true {
		_, err := os.Open("x") // новая err во внутренней области
		if err != nil {
			return // ошибка: result parameter err not in scope at return
		}
	}
	return
}
```

`:=` внутри блока объявил новую `err`. Компилятор ловит голый `return` в этом случае, но с явным `return err` затенение пройдёт молча — следите за `:=` рядом с именованными результатами.

### Результат нельзя передать «наполовину»

```go
fmt.Println(divmod(7, 2))     // можно: все результаты — аргументы
x := divmod(7, 2) + 1         // ошибка: multiple-value in single-value context
```

## Задание

Напишите функции:

- `MinMax(nums []int) (lo, hi int, ok bool)` — минимум и максимум среза. Для пустого среза — `0, 0, false`.
- `ParsePoint(s string) (x, y int, err error)` — разбирает строку вида `"3,-4"` (пробелы вокруг чисел допустимы: `" 3 , -4 "`). Если запятой нет (в том числе для пустой строки `""`), запятых больше одной или любая часть не целое число — вернуть `0, 0` и ошибку.
