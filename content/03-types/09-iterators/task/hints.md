## Подсказка 1

Адаптер возвращает новую функцию `func(yield func(T) bool)`, внутри которой обходит исходный итератор обычным `for v := range seq`. Каждый `yield` проверяйте: `if !yield(v) { return }` — `return` из тела цикла остановит и исходный итератор.

## Подсказка 2

`Fib` — бесконечный цикл `for` с парой `a, b := 0, 1` и шагом `a, b = b, a+b`. Остановить его может только `yield`, вернувший `false`, поэтому проверка результата здесь обязательна.

## Подсказка 3

В `Take` проверьте `n <= 0` до обхода `seq`. Счётчик заводите внутри возвращаемой функции, а не снаружи — иначе второй обход начнётся с исчерпанным счётчиком. После выдачи `n`-го элемента выходите сразу, не дожидаясь следующей итерации: иначе `seq` успеет выдать лишний элемент.
