## Подсказка 1

Метод можно объявить на именованном типе-map: `func (m MapGetter) Get(key string) (string, bool)`. Форма `v, ok := m[key]` различает «ключа нет» и «значение пустое», а чтение из `nil`-map просто возвращает нулевое значение.

## Подсказка 2

`Chain` — срез интерфейсов. Пройдите по нему `range`, пропуская `g == nil`, и верните первый результат с `ok == true`. Ориентируйтесь на `ok`, а не на непустую строку: пустое значение — тоже найденное.

## Подсказка 3

Проверки реализации пишутся на уровне пакета: `var _ Getter = MapGetter(nil)` и `var _ Getter = Chain(nil)`. Вложенные цепочки заработают сами: `Chain` реализует `Getter`, значит может лежать внутри другой `Chain`.
