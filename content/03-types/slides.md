# Типы и абстракции

Обзор модуля для показа команде: как Go обходится без классов и наследования — структуры, методы, неявные интерфейсы, generics и итераторы.

---

## Структура вместо класса

| C# | Go |
|---|---|
| `class` — ссылка, `struct` — значение | только `struct`-значение; разделяемость — явный `*T` |
| конструктор | функция `NewX(...)` или полезное нулевое значение |
| `==` у `record` по полям | `==` у структуры всегда по полям (если все поля сравнимы) |

- Присваивание и передача в функцию копируют все поля.
- Литерал пишут с именами полей: `Point{X: 1, Y: 2}` — переживёт добавление поля.

---

## Методы: получатель — явный параметр

```go
type Counter struct{ n int }

func (c Counter) Value() int { return c.n } // копия
func (c *Counter) Inc()      { c.n++ }      // меняет исходный

var c Counter // нулевое значение готово к работе
c.Inc()       // компилятор сам берёт &c
```

- Метод можно повесить на любой свой тип (`type Celsius float64`), но не на чужой.
- Если хоть одному методу нужен `*T` — делайте указателем все.

## Интерфейсы реализуются неявно

- Никакого `: IShape`: есть все методы — значит, реализует.
- Интерфейс объявляет **потребитель**, и он маленький: `io.Reader`, `fmt.Stringer`, `error` — по одному методу.
- «Принимай интерфейсы, возвращай структуры»: конструктор отдаёт `*UserService`, а не интерфейс.
- Опечатку в сигнатуре ловит проверка рядом с типом:

```go
var _ Shape = Square{} // не скомпилируется, если Square не реализует Shape
```

## Интерфейсное значение — два слова

Внутри интерфейса — пара (динамический тип, значение). `nil` он только когда пусты оба слова:

```go
func find() error {
	var err *NotFoundError // nil-указатель
	return err             // интерфейс (тип *NotFoundError, nil)
}
fmt.Println(find() == nil) // false
```

`obj is Dog d` → `d, ok := v.(Dog)`; без `ok` при несовпадении — паника.

## Перечисления без `enum`

```go
type Weekday int

const (
	Sunday Weekday = iota // 0, дальше выражение повторяется
	Monday                // 1
	Tuesday               // 2
)
```

- Имя значения — только через свой метод `String()`; `Weekday(42)` допустим.
- Полноты `switch` компилятор не проверяет — нужен `default`.
- Нулевое значение — первая константа: начинайте с `Unknown` или `iota + 1`.

## Встраивание вместо наследования

- `type Admin struct { User; Level int }` — поля и методы `User` продвигаются: `a.Name`, `a.Greet()`.
- `Admin` не является `User`: его нельзя передать туда, где ждут `User`, — подходит только интерфейс.
- Виртуальных методов нет: метод `User` всегда вызывает методы `User`, а не «переопределённые» в `Admin`.
- Встраивание интерфейсов — аналог `IReadWriter : IReader, IWriter`.

## Generics: проще, чем в C#

| C# | Go |
|---|---|
| `where T : IEquatable<T>` | `[T comparable]` |
| `INumber<T>`, `IComparable<T>` | `~int | ~float64`, `cmp.Ordered` |
| `default(T)` | `var zero T` |

```go
func Sum[T ~int | ~float64](xs []T) T {
	var s T
	for _, x := range xs {
		s += x
	}
	return s
}
```

Нет вариантности, специализации и `new()`. Хватает интерфейса — generics не нужны.

## Итераторы: `range` по функции

```go
func Count(n int) iter.Seq[int] {
	return func(yield func(int) bool) {
		for i := range n {
			if !yield(i) { // break в цикле → yield вернул false
				return
			}
		}
	}
}
```

- Push-модель вместо `IEnumerable`/`MoveNext`: итератор сам вызывает тело цикла.
- `slices.Values`, `maps.Keys`, `slices.Collect`, `slices.Sorted` — готовые итераторы и сборщики.

## Маленькие интерфейсы связывают всё

| C# | Go |
|---|---|
| `ToString()` у каждого объекта | `String() string` — только если тип реализует `fmt.Stringer` |
| `Stream` с `Read`, `Write`, `Seek` | отдельные `io.Reader`, `io.Writer`, `io.Seeker` |
| `stream.CopyTo(other)`, `MemoryStream` | `io.Copy(dst, src)`, `bytes.Buffer` |

`Read` может вернуть `n > 0` вместе с `io.EOF` — сначала обработайте `buf[:n]`.

## Что запомнить

- Value receiver меняет копию; `T` не реализует интерфейс с методами на `*T`.
- Интерфейс с nil-указателем внутри не равен `nil` — возвращайте `nil` явно.
- Встраивание — это делегирование, а не наследование: полиморфизма нет.
- Generics — для контейнеров и алгоритмов, интерфейсы — для поведения.
- Итератор обязан остановиться, когда `yield` вернул `false`.
