В Go нет классов. Данные описываются структурой — `struct` с именованными полями, а поведение добавляется методами (следующий урок). Структура — тип-значение, как `struct` в C#: при присваивании, передаче в функцию и возврате копируются все поля.

Конструкторов нет. Любая структура имеет нулевое значение — все поля нулевые, — и хороший Go-код старается, чтобы такое значение было сразу пригодно к работе. Если нужна инициализация, пишут обычную функцию `NewX`.

## Как это в C#

- `class` — ссылочный тип, `struct` и `record struct` — значимые. В Go есть только «значимая» структура; ссылочную семантику получают явно, через указатель `*T`.
- В C# у класса может не быть публичного конструктора без параметров. В Go значение `T{}` можно создать всегда, а нулевое значение поля — это `0`, `""`, `nil`, но не «неинициализированный объект».
- `==` для `record` сравнивает поля, для `class` — ссылки. В Go `==` у структуры всегда сравнивает поля, но только если все поля сравнимы; со срезом или map внутри код не скомпилируется.
- Анонимные типы C# (`new { Name = "a" }`) доступны только для чтения и живут внутри метода. Анонимная структура Go — полноценный тип, его можно менять, сравнивать и передавать.

## Ловушки

### Структура копируется целиком

```go
func rename(u User) { u.Name = "Bob" } // меняет копию
rename(alice)
fmt.Println(alice.Name) // Alice
```

Чтобы функция могла изменить структуру, передайте указатель: `func rename(u *User)` и вызов `rename(&alice)`.

### Поле структуры из map нельзя изменить

```go
m := map[string]Point{"a": {1, 2}}
m["a"].X = 10 // ошибка компиляции: cannot assign to struct field m["a"].X in map
```

Элемент map не адресуем: достаньте копию, измените и положите обратно (`p := m["a"]; p.X = 10; m["a"] = p`) или храните указатели `map[string]*Point`.

### Литерал без имён полей ломается при изменении типа

```go
p := Point{1, 2} // зависит от порядка и количества полей
```

Добавили поле `Z` — все такие литералы перестали компилироваться, а переставили `X` и `Y` местами — тихо поменяли смысл. Для типов из других пакетов `go vet` предупреждает о литералах без имён; пишите `Point{X: 1, Y: 2}`.

## Задание

Прямоугольник задан двумя углами: `type Rect struct{ Min, Max Point }`, где `type Point struct{ X, Y int }`. Углы могут прийти в любом порядке.

Напишите три функции:

- `Normalize(r Rect) Rect` — возвращает прямоугольник, у которого `Min.X <= Max.X` и `Min.Y <= Max.Y` (по каждой оси меньшая координата уходит в `Min`). Исходное значение не меняется.
- `Grow(r *Rect, d int)` — расширяет прямоугольник на месте: `Min` уменьшается на `d` по обеим осям, `Max` увеличивается на `d`. Нормализация не выполняется. Если `r == nil`, функция ничего не делает.
- `Overlap(a, b Rect) (Rect, bool)` — пересечение двух прямоугольников (сначала нормализуйте оба). Если пересечение имеет нулевую площадь (прямоугольники не пересекаются или только касаются сторонами/углами), вернуть `Rect{}` и `false`.
