## Подсказка 1

Для `Uniq` заведите `map[T]struct{}` с уже встреченными элементами — ключом map может быть только `comparable`-тип, поэтому ограничение именно такое. Результат собирайте в новый срез `make([]T, 0, len(s))`: так и вход не меняется, и для пустого входа получается срез длины 0.

## Подсказка 2

В `GroupBy` создайте map через `make(map[K][]T)` до цикла — тогда для пустого входа вернётся пустая, но не `nil` map. `append` к отсутствующему ключу работает: `groups[k] = append(groups[k], v)`, потому что `groups[k]` вернёт `nil`-срез.

## Подсказка 3

Чтобы нулевое значение `Set` работало, создавайте map лениво в `Add`: `if s.m == nil { s.m = make(map[T]struct{}) }`. `Has` и `Len` на `nil`-map работают и так. Методы объявляются с параметром типа получателя: `func (s *Set[T]) Add(v T)`.
