Ключевого слова `enum` в Go нет. Перечисление собирают из трёх частей: именованный тип (`type Weekday int`), блок типизированных констант и счётчик `iota`, который внутри блока `const` равен номеру строки: 0, 1, 2…

Если у константы нет выражения, она повторяет выражение предыдущей — с новым `iota`. Поэтому одна строка `Sunday Weekday = iota` задаёт тип и формулу для всего блока, а `1 << iota` так же коротко даёт битовые флаги. Человекочитаемое имя значению даёт метод `String()` — его вызывает `fmt`.

## Как это в C#

- `enum Weekday { Sunday, Monday }` → `type Weekday int` + `const ( Sunday Weekday = iota; Monday )`. Константы лежат в области видимости пакета, а не внутри типа: `Monday`, а не `Weekday.Monday`.
- `[Flags]` и `1 << n` → `1 << iota`. Проверка флага — `p&Read != 0` вместо `HasFlag`.
- `ToString()` у enum C# работает сам. В Go имя появится, только если написать метод `String()` (или сгенерировать его утилитой `stringer`).
- Как и в C#, ограничения диапазона нет: `Weekday(42)` — допустимое значение. Но в C# хотя бы есть `Enum.IsDefined`; в Go проверку пишут вручную.

## Ловушки

### Любое число пролезает

```go
func open(m Mode) {}
open(42)        // компилируется: нетипизированная константа приводится к Mode
n := 42
open(Mode(n))   // тоже компилируется
```

Тип защищает только от смешивания с переменными других типов (`open(n)` не скомпилируется). Значения из JSON, БД и флагов командной строки проверяйте явно.

### Нет проверки полноты switch

```go
switch c {
case Red:
	return "red"
case Green:
	return "green"
} // Blue добавили позже — компилятор промолчит
```

Добавляйте ветку `default` с ошибкой или паникой. Внешние линтеры (`exhaustive`) умеют находить такие switch.

### Нулевое значение — тоже значение

```go
type Status int
const (
	Active Status = iota // 0
	Banned
)
var s Status // Active — хотя никто его не выставлял
```

Если «не задано» должно отличаться от любого осмысленного значения, начинайте с `Unknown Status = iota` или с `iota + 1`.

## Задание

Права доступа: `type Perm uint8` и три флага — `Read`, `Write`, `Exec` со значениями 1, 2 и 4. В шаблоне константы равны нулю — объявите их через `iota`.

Реализуйте:

- `(p Perm) String() string` — строка из трёх символов `rwx`, где отсутствующий флаг заменён на `-`: `Read|Exec` → `"r-x"`, `0` → `"---"`. Биты старше `Exec` игнорируются;
- `(p Perm) Has(q Perm) bool` — `true`, если в `p` установлены все флаги из `q`; `Has(0)` всегда `true`;
- `ParsePerm(s string) (Perm, error)` — обратное к `String`: ровно три символа, на позиции 1 — `r` или `-`, на 2 — `w` или `-`, на 3 — `x` или `-`. Любая другая строка (другая длина, другие символы, буквы не на своих местах) — ошибка, при ошибке возвращается `0`.
