## Подсказка 1

Флаги — отдельные биты: `Read Perm = 1 << iota`, а `Write` и `Exec` без выражения повторят формулу с `iota` = 1 и 2. Проверка флага — `p&Read != 0`, проверка набора флагов — `p&q == q`.

## Подсказка 2

Для `String` начните с `[]byte("---")` и замените нужные позиции буквами. Удобно завести таблицу пар (флаг, буква) — её же можно переиспользовать в `ParsePerm`. Биты старше `Exec` таблица просто не просматривает.

## Подсказка 3

В `ParsePerm` сначала проверьте `len(s) == 3`, затем для каждой позиции `i`: символ равен букве этой позиции — добавьте флаг через `|=`, равен `'-'` — ничего, иначе верните `0` и ошибку из `fmt.Errorf`.
