## Подсказка 1

`Kind` — это type switch: `switch v.(type) { case nil: ... case int: ... }`. Ветка `case nil` ловит только интерфейс без типа; nil-указатель типа `*FieldError` в неё не попадёт.

## Подсказка 2

Ветки проверяются сверху вниз. Значение может реализовывать и `error`, и `fmt.Stringer` — чтобы оно считалось ошибкой, ветка `error` должна стоять выше `fmt.Stringer`. Для `intLike` или `int64` не сработает ветка `int`: типы должны совпадать точно.

## Подсказка 3

В `FirstError` не заводите переменную `var res *FieldError` для результата: если её вернуть, получится интерфейс `(*FieldError, nil)`, который не равен `nil`. Возвращайте найденный элемент прямо из цикла, а после цикла — литерал `nil`.
